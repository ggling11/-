## 1. 한 줄 요약
**합격 기준 24개 중 24개 통과.** 경계 ⚠ 2개는 추가 시드 20판에서도 통과:
- A6 셔틀 합 봇 71.4% (기준 70% 이상) → 추가 판 72.5%
- A14 2인 전체 정지 3.4% (기준 4% 이하) → 추가 판 3.5%

조정은 데이터만 2번 했다.
- 1회차: 전체 정지 배율 0.8 → 0.7, 무시 봇의 QTE 규칙
- 2회차: 맥놀이 · 합동 필살 가중치를 올리고, 도깨비의 35% 전환 QTE를 뺌

아트는 처음 보는 에이전트 6세트가 모두 레퍼런스 쪽을 골랐다(확신 high). 비슷함 점수는 5~6/10이다(2단계 그림은 1~2/10). 같은 게임으로 착각할 수준은 아니다.

**차이 게이트**
- 픽셀화 끔 · 외곽선 · 셀 · 하프톤 보임: O (check 3A1 · 3A2)
- Oklab 색 거리 (작을수록 가까움)
  - 새 화면 → 레퍼런스 **0.0485**
  - 2단계 → 레퍼런스 0.0599
  - 새 화면 → 2단계 0.0767
  - 게이트 통과
- 처음 보는 에이전트 3회 × 2세트:
  - 6세트 모두 레퍼런스를 고름 (확신 high)
  - 비슷함 6 · 5 → 5.5 · 6 → 6 · 5 (/10)
  - 2단계 그림 비슷함은 1~2

**남은 차이 (에이전트들이 공통으로 꼽은 것)**
1. 경기장이 바닥 판 + 무늬로 보인다. 레퍼런스는 단 · 벤치 · 난간 같은 실제 지형과 소품이 빽빽하다.
2. 보스와 캐릭터가 외곽선 친 실루엣으로 읽힌다. 속 모델링이 없고 코드 도형이라서 그렇다.
3. 타격 이펙트(흰 별 불꽃 · 피해 숫자)가 적다.
4. 초상이 깔끔한 애니풍이다. 레퍼런스는 흑백 잉크 만화다.
5. 밝기와 분위기가 장면에 따라 레퍼런스보다 어둡고, 채도는 높다.

1차 검토에서 "뿌옇다"는 지적이 나와 대비를 올렸더니, 3차 검토에서는 "더 어둡다"는 지적이 나왔다. 숫자 몇 개를 고치는 것으로는 점수가 5~6에서 움직이지 않았다. 다음 아트 단계는 지형 모델 · 캐릭터 모델 · 이펙트 · 잉크 초상 중 무엇을 먼저 할지 정하는 일이다.

전역 키는 다음과 같다.
- **2P 참가:** 선택 화면에서 Enter · 숫자패드 1 · 두 번째 패드 A를 0.6초 꾹, 싸우는 중에도 같은 키를 꾹, 또는 메뉴 PLAYERS
- **2P 나가기:** F4, 메뉴 PLAYERS, 선택 화면에서 Backspace 0.6초 꾹
- **기타:** F3 = AI 파트너 켜기/끄기 · R 꾹 = 재시작
- **끝 화면:** C, 패드 Y · BACK = 캐릭터 선택
- **시작 화면:** 아무 키 · 클릭 · 패드 버튼

## 4. 패드

**6-1 의심 원인 확인 결과**

| # | 2단계 코드에서 확인한 것 | 고친 것 |
| --- | --- | --- |
| 1 | `getGamepads()`가 한 번 예외를 던지면 `padOK=false`로 영원히 끔 | 막힘 표시 + PAD.retry(1초)마다 다시 시도 |
| 2 | 버튼을 눌러야 패드가 보인다는 안내 없음 | 시작 화면 · 메뉴에 "NO PAD - PRESS A BUTTON ON IT" / "PAD 1 READY" |
| 3 | 비표준 매핑 대응 없음 | `mapping !== 'standard'`이면 PAD.fallback 표 (다시 배정 화면은 없음) |
| 4 | LT · RT를 `pressed`로만 판정 | 값 ≥ PAD.trig(0.5) |
| 5 | 매 프레임 연결 순서로 1P/2P를 다시 매김 | 처음 누른 순서로 슬롯 고정(index), 끊기면 5초 자리 유지, 같은 id가 돌아오면 다시 붙임 |
| 6 | START = 재시작 | START = 메뉴 · BACK = 끝 화면 캐릭터 선택 (2단계 BACK = 개발용 동작 보기 전환이었음 ★) |
| 7 | 임베드에서 포커스가 없으면 입력이 안 들어감 | 시작 화면 클릭 = 포커스 + 시작 |

그밖에 원형 데드존 0.25(다시 늘림)을 쓰고, 연결 직후 스틱은 한 번 쉬는 값을 볼 때까지 무시하고, 패리 성공 때 짧은 진동(지원할 때만)을 준다.

**가짜 패드 시나리오** (check 3P1 · 3P2, 실제 패드 없이 `navigator.getGamepads`를 바꿔 끼움): 아래가 전부 통과했다.
- 표준 A → 1P 배정
- 빈 칸이 섞인 배열
- 두 번째 패드 → 2P
- 1P 패드가 끊겨도 2P 그대로
- 같은 패드 다시 연결 → 1P
- START = 메뉴
- SecurityError → 에러 없이 재시도
- 트리거 0.3 무시 / 0.7 = 스킬
- 스틱 떨림 0.15 무시 / 0.8 = 이동
- 비표준 = 대체 표
