# 쿼터뷰 듀오 보스 액션 (가제) — 기획 초안

## 한 줄 컨셉
3D 툰 렌더링 쿼터뷰 보스 공략 액션.
혼자 하면 태그 액션(젠레스 존 제로, 명조 느낌), 둘이 하면(로컬) 각자 움직이며
**복식 경기를 할 때의 감정**으로 보스를 공략한다.

## 레퍼런스
- **엘든 링 밤의 통치자**: 보스 중심 협동 공략, 크고 읽히는 보스 패턴
- **젠레스 존 제로 / 명조**: 솔로 태그 교체 액션
- **테니스·배드민턴 복식**: 형태가 아니라 **감정** 레퍼런스

## 설계 원칙
> 복식의 형태(공, 네트, 랠리, 코트)는 가져오지 않는다. 복식할 때 **느끼는 감정**만 가져온다.
> 모든 메커니즘은 "이게 아래 감정 중 무엇을 만드는가?"에 답할 수 있어야 한다.

## 목표 감정 → 메커니즘 (후보)
| 복식에서 느끼는 감정 | 게임에서 만드는 방법 |
|---|---|
| **합이 맞는 쾌감** — 말 없이 맞아떨어지는 순간 | 두 캐릭터의 공격이 짧은 타이밍 안에 겹치면 추가 효과 + 강한 이펙트/사운드 피드백 |
| **등을 맡기는 신뢰** | 보스는 한 명에게 집중(포커스)하고, 다른 한 명은 그 사이 딜 찬스. 포커스는 주기적으로 넘어감 |
| **"내 거 / 네 거" 순간 판단** | 둘 중 한 명만 받아내면 되는 보스 공격. 누가 받을지 즉시 판단해야 함 |
| **찬스를 만들어 주고, 끝내 주는 기쁨** | 그로기를 만든 사람이 아니라 파트너가 마무리할 때 최대 피해 |
| **자연스럽게 흐르는 역할 교대** | 포커스를 받는 쪽 / 치는 쪽이 계속 바뀜. 솔로에서는 태그 교체가 이 역할 |
| **실수를 메워 주는 고마움** | 파트너가 맞기 직전 끼어들어 막는 지원 패링, 쓰러진 파트너 구조 |

## 감정 우선순위 (확정)
1. **합이 맞는 쾌감** — 최우선
2. **등을 맡기는 신뢰**
3. **"내 거 / 네 거" 순간 판단** — 감정은 유지, 장치는 재검토 (아래)
4. 나머지 (찬스 만들고 끝내 주기 / 역할 교대 / 실수 메워 주기)

### 1 + 2를 하나의 루프로
보스가 한 명에게 집중 → 그 사람이 버티거나 받아내는 순간, 파트너의 공격이 겹치면 "합" 발동.
**신뢰(2)가 판을 깔고, 합(1)이 보상으로 터지는 구조.**

### "내 거 / 네 거" 장치 재검토
기존안("한 명만 받아내면 되는 공격")은 규칙으로 강제하는 느낌이라 보류.
감정이 **위치와 상황에서 저절로** 생기게 하는 방향으로 다시 찾는다.

- **안 A — 받는 사람과 치는 사람이 갈림** ← **채택. 아래 "핵심 메커니즘" 참고**
- 안 B — 사이를 노리는 공격: 보스가 두 사람의 중간 지점을 노림. → A 위에 얹는 **보스 패턴**으로 사용
- 안 C — 캐릭터별 강점: 캐릭터마다 잘 받는 공격 종류가 다름. → 보류 (캐릭터 설계 단계에서 재검토)

## 핵심 메커니즘: 받기와 틈 (안 A)

### 한 문장
**한 명이 받아내면, 보스의 틈은 파트너 쪽으로 열린다.**

### 용어
| 용어 | 뜻 |
|---|---|
| **받기** | 보스 공격을 정면으로 받아내는 행동 (패링/가드). 회피와 다름 |
| **틈** | 받기 성공 직후 보스에게 생기는 짧은 빈틈 |
| **합** | 파트너의 공격이 틈 안에 들어간 것 |
| **완벽한 합** | 파트너의 공격이 받기와 거의 동시에 들어간 것 |

### 기본 루프
1. 보스가 한 명을 노리고 예비 동작을 보인다
2. 노려진 사람이 선택한다 — **피한다**(안전, 이득 없음) / **받는다**(위험, 틈 생성)
3. 받기 성공 → 보스가 받은 쪽으로 몸이 쏠리며 **반대편(측면·등)에 틈**이 열린다
4. 파트너가 틈을 치면 **합** 발동
5. 보스는 자기를 친 사람에게 화가 나서 **노리는 대상이 바뀐다** → 이번엔 그 사람이 받는 쪽

→ 5번 덕분에 **받는 쪽 / 치는 쪽이 저절로 교대**된다 (우선순위 4의 "역할 교대"가 공짜로 따라옴).

### 왜 "규칙"이 아니라 "감정"으로 느껴지는가
- 받은 사람이 반격하지 못하는 이유가 **규칙이 아니라 몸**에 있다
  - 받은 사람은 반동으로 짧게 경직된다
  - 틈은 **받은 사람 반대편**에 열린다 → 공간적으로 파트너만 닿는다
- 둘 다 받으려 들면 → 둘 다 경직, 보스 정면만 버티고 측면엔 아무도 없음 → 틈이 허공에 사라짐
  - 벌칙이 아니라 **기회를 날린 아쉬움**. "다음엔 한 명만 받자"를 스스로 깨닫는다
- 아무도 안 받으면 → 둘 다 안전하지만 아무 일도 안 일어남

### 우선순위 감정과의 연결
| 감정 | 이 메커니즘에서 생기는 순간 |
|---|---|
| **1. 합의 쾌감** | 받기와 파트너 공격이 맞물리는 순간. 동시에 가까울수록 크게 터진다 |
| **2. 신뢰** | **완벽한 합을 노리려면 파트너는 받기가 성공하기 전에 이미 공격을 시작해야 한다.** 파트너가 받아낼 거라고 믿고 미리 휘두르는 것 = 신뢰 |
| **3. 내 거 / 네 거** | 보스 공격이 올 때 "내가 받을게 / 네가 받아" — 둘 다 받으면 손해라서 자연스럽게 생김 |
| 4. 찬스 만들고 끝내 주기 | 받은 사람이 판을 깔고, 파트너가 끝냄 |
| 4. 역할 교대 | 친 사람에게 보스 시선이 넘어감 |

### 받기 품질 (받는 사람도 주인공이어야 한다)
받는 쪽이 "보조 역할"로 느껴지지 않게, **받기를 잘할수록 틈이 커진다.**

| 받기 | 판정 | 결과 |
|---|---|---|
| **정확한 받기** | 타격 직전 짧은 타이밍 | 큰 틈 (길고, 보스 크게 휘청) |
| **버티기** | 가드 유지 | 작은 틈 (짧음), 받은 사람 체력/기력 소모 |

→ "네가 잘 받아 줘서 내가 크게 쳤다"가 성립한다.

### 합 등급 (초기 수치, 조정 대상)
| 등급 | 파트너 공격 적중 시점 (받기 기준) | 효과 |
|---|---|---|
| **완벽한 합** | 0 ~ 0.25초 | 피해 ×3, 강한 히트스톱 + 전용 연출 |
| **합** | 0.25초 ~ 틈 종료 | 피해 ×2, 연출 |
| 일반 | 틈 밖 | 피해 ×1 |

- 틈 길이: 정확한 받기 1.5초 / 버티기 0.8초
- 정확한 받기 판정창: 0.15초

### 합의 피드백 (쾌감은 여기서 결정된다)
- 히트스톱 (완벽한 합은 길게)
- 두 캐릭터가 동시에 강조되는 연출 — 툰 외곽선 색 번쩍임
- 두 음이 겹치는 화음 같은 타격음 (받기음 + 타격음이 하나의 소리로 들리게)
- 카메라 미세 줌/흔들림
- UI는 최소화. 숫자보다 **느낌**으로 알게

### 받기 의도 읽기 (말 없이 맞추기 위해)
- 받기 자세에 들어가면 캐릭터에 뚜렷한 시각 신호 (자세 변화 + 발밑 표시)
- 파트너는 화면만 보고 "쟤가 받는다 → 나는 돌아 들어간다"를 판단할 수 있어야 한다

### 솔로 (태그)
- 캐릭터 A로 받기 → **태그하면 B가 틈 쪽으로 진입하며 공격** (태그 진입 공격 = 틈 공격)
- 받기 직후 빠르게 태그할수록 완벽한 합
- 솔로에서는 "받기 → 태그"가 한 사람 손 안의 리듬이 된다

### 보스 설계 지침
- **받기 가능 공격**과 **피해야만 하는 공격**(잡기, 광역 등)을 섞는다 → 매번 "받을까, 피할까" 판단
- 예비 동작은 크고 읽히게 (밤의 통치자 스타일)
- 응용 패턴
  - **사이 공격 (안 B)**: 두 사람의 중간을 노림 → 누가 받을지 즉석 판단
  - **연속 공격**: 여러 번 받아야 함. 마지막 받기에서 큰 틈
  - **동시 공격 (후반 페이즈)**: 둘을 동시에 노림 → 둘 다 받아야만 열리는 "맞받기" 틈. 평소 규칙을 뒤집는 클라이맥스

### 위험 요소와 대응
| 위험 | 대응 |
|---|---|
| 받는 쪽이 재미없음 | 받기 품질로 결과가 달라짐 + 역할이 계속 교대됨 |
| 치는 쪽이 계속 때리기만 함 | 틈 밖 공격은 약하고, 때릴수록 보스 시선을 끌어 다음 타깃이 됨 |
| 로컬에서 말로만 소통 | 받기 의도를 시각 신호로 보여 줌 |

### 프로토타입 범위
- 보스 1: 큰 캡슐. 공격 3종
  - 내려찍기 (받기 가능)
  - 돌진 (받기 가능, 직선)
  - 충격파 (받기 불가, 피해야 함)
- 캐릭터 2: 기본 공격, 받기, 회피, (솔로) 태그
- 로컬 2인 입력 (키보드 분할 + 패드)
- 기본 툰 셰이더
- 확인할 것: **완벽한 합이 터질 때 "와" 소리가 나오는가**
- 구현: `prototype/index.html` (Three.js, 브라우저에서 바로 실행). 게임 중 ` 키로 수치와 아트 스타일 조정

### 솔로에서의 같은 감정
솔로는 "나와 내 두 번째 캐릭터의 호흡". 태그 진입 타이밍이 곧 파트너의 행동이 된다.
(예: 그로기 직후 태그 진입 = 파트너 마무리, 피격 직전 태그 = 지원 패링)

## 플레이 모드
| 모드 | 조작 | 핵심 |
|---|---|---|
| 솔로 | 캐릭터 2명을 태그로 교체 | 혼자서 두 역할을 오가는 태그 플레이 |
| 듀오 (로컬) | 각자 캐릭터 1명 | 두 사람이 역할을 주고받는 협동 플레이 |

솔로와 듀오는 **같은 전투 규칙**을 쓴다.

## 비주얼
- 3D, 쿼터뷰 고정 카메라
- 툰 렌더링 (셀 셰이딩 + 외곽선). 스타일 변형은 셰이더/팔레트 교체로 비교.
