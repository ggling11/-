# 쿼터뷰 듀오 보스 액션 (가제) — 기획 초안

## 한 줄 컨셉
3D 툰 렌더링 쿼터뷰 보스 공략 액션.
혼자 하면 태그 액션(젠레스 존 제로, 명조 느낌), 둘이 하면(로컬) 각자 움직이며 **테니스/배드민턴 복식** 같은 호흡으로 보스를 공략한다.

## 플레이 모드
| 모드 | 조작 | 핵심 |
|---|---|---|
| 솔로 | 캐릭터 2명을 태그로 교체 | 전위/후위를 혼자 빠르게 오가는 태그 플레이 |
| 듀오 (로컬) | 각자 캐릭터 1명 | 두 사람이 포지션을 나눠 맡는 복식 플레이 |

솔로와 듀오는 **같은 전투 규칙**을 쓴다. 솔로의 태그 교체 = 듀오의 로테이션.

## 복식 전투 메커니즘 (후보)
- **전위 / 후위**: 보스 가까이에서 붙잡는 역할과 뒤에서 원거리·지원하는 역할. 위치에 따라 성능이 달라진다.
- **로테이션**: 둘이 자리를 바꾸면 보너스. 솔로에서는 태그 교체 연계기.
- **띄워주기 → 스매시**: 한 명이 보스를 그로기/경직시키면 파트너가 마무리해 큰 피해.
- **랠리**: 보스의 투사체·공격을 패링해 되받아치고, 파트너가 이어받아 증폭.
- **커버**: 한 명이 노려질 때 파트너가 끼어들어 막아 줌 (지원 패링).

## 보스 설계 방향
- 보스는 "네트 건너편 상대 팀"처럼 설계: 한 명을 노리는 패턴과 둘 사이 빈 공간을 노리는 패턴을 섞는다.
- 패턴은 서브/스매시처럼 읽을 수 있는 예비 동작을 가진다.

## 비주얼
- 3D, 쿼터뷰 고정 카메라
- 툰 렌더링 (셀 셰이딩 + 외곽선). 스타일 변형은 셰이더/팔레트 교체로 비교.

## 기술
- 엔진: Godot 4 (3D + 툰 셰이더 + 로컬 2인 입력)
- 프로토타입 단계는 캡슐/기본 도형 또는 CC0 에셋 사용
