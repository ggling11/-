# D. 캐릭터와 태그 연계

> 세션 D의 실험 기록. 확정 사항(감정 우선순위, 받기와 틈, 복식은 감정 레퍼런스, 모바일 아님)은 그대로 둔다.
> 기획서의 **안 C(캐릭터별 강점)**를 캐릭터 설계 단계에서 다시 꺼내, "받기와 틈" 위에 얹는다.

---

## 1. 출발점: 안 C를 "규칙"이 아니라 "위치"로

안 C를 그대로 쓰면 "이 공격은 모루가 받아야 한다"는 **암기 규칙**이 된다. 이것은 기획서가 보류한 이유("규칙으로 강제하는 느낌")와 같다.

그래서 한 단계를 끼운다.

> **거리 → 공격 종류 → 누구 몫**

- 보스는 이미 **가까우면 내려찍기, 멀면 돌진**을 고른다 (프로토타입 `choose()`).
- 그렇다면 **가까이 붙는 캐릭터가 내려찍기를 잘 받고, 멀리 도는 캐릭터가 돌진을 잘 받게** 만든다.
- 결과: 각 캐릭터가 **자기 스타일대로 서 있기만 해도** 자기에게 맞는 공격이 온다. "내 거 / 네 거"가 암기가 아니라 **서 있는 자리**에서 생긴다.
- 반대로 자리가 꼬이면(제비가 보스 코앞에 있다) 버거운 공격이 온다. 이때 "피할까, 버겁게라도 받을까, 모루한테 넘길까"가 판단이 된다.

## 2. 두 캐릭터

### 모루 — 받쳐 내는 손
모루(대장간 모루)처럼 **내리치는 것을 받쳐 낸다**. 낮고 넓은 몸에 망치.

| 항목 | 내용 |
|---|---|
| 잘 받는 공격 | **내려찍기, 사이 내려찍기** (위에서 오는 무거운 것) |
| 버거운 공격 | 돌진 (옆에서 밀고 들어오는 것) |
| 치기 | 느리고 무거운 한 방. 예비 동작 0.3초, 피해 18 |
| 파고드는 거리 | 짧다 (2.4) — 틈이 가까울 때만 닿는다 |
| 시선 끌기 | 한 대가 시선 2만큼. 때리면 금방 노려진다 → 노려지면 보스가 붙어서 내려찍기 → 모루 몫 |
| 회피 | 짧고 둔하다 |
| 태그 진입 | **모루 낙하** — 위에서 떨어지며 약점에 내려친다 |
| 맞장구 | 보스 휘청임을 0.5초 늘린다 |

**신뢰가 몸에 박힌 캐릭터.** 예비 동작이 0.3초라, 완벽한 합(받기 후 0.25초 안)을 노리려면 **파트너가 받기 성공하기 전에 이미 망치를 들어야 한다.** 기획서의 "받기 성공을 보기 전에 휘둘러야 한다"가 모루에게는 선택이 아니라 필수다.

### 제비 — 흘려 내는 발
제비처럼 **옆으로 스치며 흘려 낸다**. 가늘고 긴 몸에 긴 칼, 꼬리 천.

| 항목 | 내용 |
|---|---|
| 잘 받는 공격 | **돌진** (옆으로 흘려 보낸다) |
| 버거운 공격 | 내려찍기 계열 |
| 치기 | 빠르고 가볍다. 예비 동작 0.1초, 피해 7 |
| 파고드는 거리 | 길다 (5.2) — 멀리서도 틈으로 날아든다 |
| 합 연타 | 합을 친 칼이 **두 번 더 이어진다** (피해는 작지만 합의 순간이 길어진다) |
| 시선 끌기 | 한 대가 시선 1 |
| 회피 | 길고 빠르다 |
| 태그 진입 | **제비 날기** — 멀리서 날아 들어와 벤다 |
| 맞장구 | 보스 휘청임을 0.2초 늘린다 |

**거리를 믿는 캐릭터.** 틈이 멀리서 열려도 닿는다. 모루가 받는 순간 제비는 멀리 있어도 된다 → 받는 사람은 "제비가 어디 있든 들어올 거야"를 믿는다.

### 받기 상성 (구현 수치)
| | 잘 맞음 (◆) | 보통 | 버거움 |
|---|---|---|---|
| 정확한 받기 판정창 | ×1.6 (0.24초) | ×1 (0.15초) | ×0.5 (0.075초) |
| 틈 길이 | ×1.25 | ×1 | ×0.6 |
| 받은 사람 반동 | ×0.7 | ×1 | ×1.6 + 멀리 밀려남 |
| 버티기 깎이는 피해 | ×1 | ×1 | ×2 |

- **버거워도 받을 수는 있다.** 완전히 막지 않는 것이 핵심. 위기 때 "버겁지만 내가 받는다"는 선택이 남아야 등을 맡기는 장면이 생긴다.
- 잘 맞는 받기는 **반동이 짧다** → 다음에 나올 맞장구까지 이어진다. 받는 사람의 강점이 "틈이 크다"에서 끝나지 않고 다음 박자로 넘어간다.

## 3. 맞장구 — 받은 사람에게 돌아오는 박자 (새 제안)

받기와 틈의 기본 루프는 **두 박자**다: 받기 → 합.
받은 사람은 판을 깔고 끝난다. "받는 쪽도 주인공"을 한 단계 더 밀기 위해 **세 번째 박자**를 둔다.

> **합 직후 휘청이는 보스를, 받았던 사람이 치면 맞장구.** (×1.5, 한 번만)

- 이름은 장단에 "맞장구를 친다"에서. 말 없이 박자를 주고받는 느낌.
- 받은 사람은 반동 때문에 **틈은** 못 친다 (확정 규칙 그대로). 하지만 반동이 풀린 뒤 **휘청임**은 칠 수 있다.
- 리듬: **받고(나) → 치고(너) → 받아치고(나)**. 복식에서 "네가 받아 준 공을 내가 꽂고, 네가 마무리"하는 주고받음의 감정.
- 시선 교대는 그대로다. 맞장구는 시선을 가져오지 않는다 (합을 친 사람이 다음 타깃).
- 휘청임 시간을 0.7/1.0 → 0.9/1.2초로 늘렸다. 맞장구가 닿을 시간이 필요하다.

| 감정 | 맞장구에서 |
|---|---|
| 1. 합의 쾌감 | 합 뒤에 짧은 두 번째 화음이 따라온다 (두 음 → 세 음) |
| 2. 신뢰 | 합을 친 사람은 "받은 쪽이 이어 줄 거야"를 믿고 휘청임을 건드리지 않고 비켜 준다 |
| 4. 찬스 만들고 끝내 주기 | 판을 깐 사람이 마지막을 끝낸다. 방향이 한 번 더 돈다 |

## 4. 솔로 태그 연계기

솔로는 "나와 내 두 번째 캐릭터의 호흡". 태그 버튼 하나(Q)로 네 가지 연계가 나온다.

| 연계 | 입력 | 일어나는 일 | 감정 |
|---|---|---|---|
| **틈 진입** (기존) | 받기 성공 → Q | 대기 캐릭터가 틈 쪽에서 등장하며 공격 = 합. 빠를수록 완벽한 합 | 합 |
| **캐릭터별 진입** (새) | 위와 같음 | 모루: 위에서 떨어지며 내려친다 / 제비: 멀리서 날아와 베고 두 번 더 이어진다 | 합의 맛이 캐릭터마다 다름 |
| **되돌려 태그** (새) | 합이 터진 직후 → 한 번 더 Q | 받았던 캐릭터가 휘청이는 보스 옆으로 돌아와 **맞장구**. 합 직후 태그 쿨다운이 풀린다 | 찬스 만들고 끝내 주기 |
| **미리 태그** (새, 판단) | 보스 예비 동작 중 Q | 오는 공격에 맞는 캐릭터로 바꿔서 받는다. 대기 카드에 "◆ 내 몫"이 뜬다 | 내 거 / 네 거 |

### 한 손 안의 리듬 예시
- **가까이 (내려찍기)**: 모루로 받기 → Q 제비 날기(합 + 연타) → Q 모루 낙하(맞장구) — "쿵, 챡챡챡, 쿵"
- **멀리 (돌진)**: 제비로 흘리기 → Q 모루 낙하(합, 큰 한 방) → Q 제비 날기(맞장구) — "슥, 쾅, 챡"
- **꼬였을 때**: 제비가 붙어 있는데 내려찍기 예비 동작 → Q 미리 태그로 모루 → 받기. 미리 태그를 하면 받은 뒤 틈 진입은 다시 제비가 하게 된다 → 같은 리듬으로 돌아온다.

미리 태그와 틈 진입이 둘 다 Q라서, **한 번 받는 데 Q를 두 번(미리 바꾸고, 다시 들어가고)** 쓰는 판단이 생긴다. 솔로에서 "내 거 / 네 거"는 이 판단이 맡는다.

## 5. 듀오에서의 역할 차이

같은 규칙이지만 두 캐릭터가 **다른 자리**를 좋아해서 역할이 저절로 갈린다.

| | 모루 | 제비 |
|---|---|---|
| 좋아하는 자리 | 보스 코앞 (앞마당) | 보스 바깥 원 (멀리 돌기) |
| 주로 받는 공격 | 내려찍기, 사이 내려찍기 | 돌진 |
| 합을 칠 때 | 가까운 틈을 큰 한 방으로. 미리 휘두르는 신뢰 | 먼 틈으로 날아드는 연타 |
| 시선 | 잘 끈다 (2배). 붙어서 때리면 금방 노려진다 | 덜 끈다. 치고 빠진다 |
| 맞장구 | 휘청임을 크게 늘려 다음 합까지 숨을 벌어 준다 | 짧고 가볍다 |

### 흐름 예시 (듀오)
1. 모루가 붙어서 때림 → 시선이 모루로 → 보스가 내려찍기 → 모루 정확한 받기(◆, 틈 큼)
2. 멀리 있던 제비가 날아들어 합 + 연타 → 시선이 제비로
3. 반동이 짧은 모루가 망치로 맞장구
4. 제비는 보스 코앞이라 내려찍기가 오기 전에 **멀리 빠진다** → 거리가 벌어져 보스가 돌진 → 제비가 흘리기(◆)
5. 모루가 가까운 틈에 미리 휘둘러 완벽한 합 → 시선이 모루로 → 1로

**제비의 "빠지는 움직임"**이 다음 역할의 준비가 된다. 치고 나서 할 일이 생긴다(기획서 위험 요소 "치는 쪽이 계속 때리기만 함"에 대한 답).

### 사이 내려찍기
둘 사이를 노리면 **둘 다 받을 수 있는 위치**가 된다. 내려찍기 계열이니 모루 몫(◆). 제비가 같이 받으면 버겁고, 둘 다 받으면 칠 사람이 없다 → "모루한테 맡기고 나는 돈다"가 상성과 기본 규칙 양쪽에서 같은 방향으로 밀린다.

## 6. 읽히는 신호 (말 없이 맞추기)
- 실루엣: 모루는 **낮고 넓게, 망치**. 제비는 **가늘고 길게, 긴 칼, 꼬리 천**. 쿼터뷰에서 크기만으로 구분된다.
- **◆ 내 몫**: 보스 예비 동작 중, 그 공격을 잘 받는 캐릭터 머리 위에 금색 마름모. 솔로에서는 대기 카드에 표시. 배우는 단계용 — 조정 패널에서 끌 수 있다.
- 받기 결과 글자: 잘 맞으면 "모루의 몫", 버거우면 "버겁다".
- 맞장구: 합보다 작은 두 음 화음 + 친 사람 색 파편.

## 7. 프로토타입에 들어간 것

`prototype/index.html` (이 브랜치)
- `CHARS` — 모루/제비 수치, `fit()` 받기 상성, `FIT` 배율
- 실루엣 차별화, ◆ 표시, 받기 상성(판정창·틈·반동·밀려남)
- 공격 차이(예비 동작·피해·파고드는 거리·시선 가중치), 회피 차이
- 제비 합 연타, 캐릭터별 태그 진입(낙하/날기), 되돌려 태그, 맞장구
- 결과 화면과 통계에 맞장구, 잘 맞는 받기 추가
- 조정 패널 `캐릭터` 폴더: **캐릭터 차이 켜기/끄기**(끄면 이전 프로토타입과 같은 공통 수치), ◆ 표시, 배율, 캐릭터 수치
- 배치: 둘이 하기 1P=모루, 2P=제비. 혼자 하기와 연습은 A=모루, B=제비
- 스모크 테스트 추가: 받기 상성, 듀오 맞장구, 솔로 받기→Q 합→Q 맞장구

## 10. 확인이 필요한 것 (사용자)
1. **맞장구**(받은 사람이 휘청임을 치는 세 번째 박자) 방향이 좋은가? "받은 사람은 반동으로 못 친다"와 충돌한다고 느껴지면 끌 수 있게 바꾸겠다.
2. 모루 이름/제비 이름, 그리고 "위에서 오는 것 / 옆에서 오는 것" 상성 축이 마음에 드는가?
3. 캐릭터 수: 2명 고정(모루·제비) vs 로스터. 지금 설계는 2명 고정에서도 완결되게 했다.
4. 둘이 하기에서 1P/2P 캐릭터 바꾸기가 필요한가? 지금은 1P=모루 고정 (패드를 바꿔 잡으면 된다는 가정).
5. 휘청임을 0.9/1.2초로 늘린 것 — 보스가 너무 오래 멈춰 있다고 느껴지는가?
