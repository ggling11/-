# 알파 · 캐릭터 구성 (인터뷰 결과)

> 이 문서는 `docs/실험/알파.md` 12절의 **테마 앵커링 방지 프롬프트**를 따른다.
> 메커니즘을 먼저 쓰고, 이름·외형은 맨 끝 "스킨" 칸에만 쓴다. 스킨 칸을 지워도 설계는 완성돼 있어야 한다.

## 0. 인터뷰로 정한 것

| 항목 | 결정 |
|---|---|
| 구성 | 로스터 **4명** 중 2명을 골라 짝 (짝 6가지) |
| 역할 | **모두 받고 모두 친다.** 받는 사람/치는 사람은 보스 시선이 정한다 |
| 받기 | **모두 같다.** 받기 상성(◆ 내 몫)은 쓰지 않는다 |
| 색 | **자리 색** (1P 주황 / 2P 파랑). 캐릭터와 무관 |
| 차이 | ① **무게**(무거움 2 · 가벼움 2) ② **고유 기술**(공격 길게 누르기, 1개) ③ **교차 베기 기여**(조합형) |
| 고유 기술 | **끊기**(시간을 다룬다), **꿰뚫기**(공간을 다룬다) |
| 교차 베기 효과 | **무너뜨리기**(그로기)만. 다른 후보(짐 덜기·시선 끊기·박자 끌기)는 기각 |
| 구성 방식 | **무게 × 기술 = 2×2** |

## 1. 한 문장

> **무게는 "언제 휘두르기 시작하느냐"를, 기술은 "무슨 문제를 푸느냐"를 정한다.**
> 끊기는 **시간 문제**(공격이 오는데 아무도 못 받는다)를, 꿰뚫기는 **공간 문제**(틈이 반대쪽에 열렸다)를 푼다.

## 2. 축 1 · 무게 (기본 공격의 손맛)

| | 무거움 | 가벼움 |
|---|---|---|
| 예비 동작 | 0.28초 | 0.10초 |
| 피해 | 18 | 7 (합을 치면 칼이 두 번 더 이어짐) |
| 파고드는 거리 | 짧다 (2.4) | 길다 (5.2) |
| 시선 끌기 | 한 대에 2 | 한 대에 1 |
| 회피 | 짧고 둔함 | 길고 빠름 |
| 솔로 태그 진입 | 위에서 떨어지며 | 멀리서 날아들며 |
| 교차 베기 기여 (무너뜨리기) | 그로기 **+30** | 그로기 **+15** |

**감정 답:**
- **합.** 완벽한 합(받기와 동시)과 교차 베기(두 타격 0.2초 안)를 맞추려면 무거운 쪽은 **더 일찍** 휘둘러야 한다.
- 짝의 무게가 다르면 "내가 먼저, 너는 조금 뒤에"를 몸으로 익혀야 한다. 같은 무게끼리는 맞추기 쉽지만 할 수 있는 게 겹친다.

## 3. 축 2 · 고유 기술 (공격 길게 누르기, 입력 공통)

### 끊기 — 시간을 다룬다
누르고 있으면 모으고, 놓으면 내려친다. **보스 예비 동작 중에 맞으면 공격을 끊는다(가로채기).**

| | 무거운 끊기 | 가벼운 끊기 |
|---|---|---|
| 모으는 시간 | 0.6초 | 0.3초 |
| 피해 | ×2.5 | ×1.5 |
| 끊는 방식 | **완전히 끊음**: 공격 취소, 보스 1.0초 휘청 | **박자를 민다**: 공격은 안 끊기고 예비 동작이 0.4초 늘어난다 |
| 그로기 | +20 | +8 |
| 쓰임 | 한 번 크게. "이건 내가 끊는다" | 짧게 자주. 파트너가 받을 자세를 잡을 시간을 벌어 준다 |

- 감정: **실수 메워 주기**(파트너가 못 받을 것 같을 때 내가 시간을 해결), 무거운 끊기는 **내 거/네 거**(받을까, 끊을까).
- 가벼운 끊기는 공격을 지우지 않는다 → 받기와 틈 규칙을 대체하지 않고 **돕는다**. 유물 "방패 망치"는 끊기 계열 전체에 적용.

### 꿰뚫기 — 공간을 다룬다
누르고 있으면 방향을 잡고, 놓으면 **보스를 관통해 반대편으로 빠져나가며** 벤다.
**타격 방향은 빠져나간 쪽으로 친다.** 그래서:
- 틈이 반대쪽에 열려도 꿰뚫어 지나가면 **열린 쪽에서 친 것**이 된다 → "반대쪽!"을 혼자 푼다.
- 파트너와 같은 쪽에 서 있어도 꿰뚫으면 **반대쪽 타격**이 된다 → 교차 베기를 혼자서 만들 수 있다(파트너 타격과 0.2초 안이면).

| | 무거운 꿰뚫기 | 가벼운 꿰뚫기 |
|---|---|---|
| 모으는 시간 | 0.5초 | 0.25초 |
| 돌진 | 느리다 (0.25초), 짧다 (보스 바로 뒤에 멈춤) | 빠르다 (0.12초), 길다 (보스 뒤 3m까지) |
| 피해 | ×2 | ×1.2 |
| 무적 | 없음 (지나가는 동안 맞을 수 있다) | 지나가는 동안 무적 (회피 겸용) |
| 쓰임 | 틈 쪽으로 확실히 들어가 크게 친다 | 위험한 자리에서 빠져나오며 반대편 자리를 잡는다 |

- 감정: **합**(교차 베기를 만드는 사람), **역할 교대**(꿰뚫고 나가면 보스 등 뒤 = 다음엔 파트너가 노려짐).
- 위험: 관통 후 보스 시선은 그대로 → 무거운 꿰뚫기는 뒤에서 맞을 수 있다.

## 4. 네 명 (메커니즘만)

| 칸 | 무게 | 기술 | 한 줄 | 교차 베기 기여 |
|---|---|---|---|---|
| **A** | 무거움 | 끊기 | 앞에 서서 받고, 못 받을 공격은 **끊는다**. 지금 프로토타입의 모루 | 그로기 +30 |
| **B** | 무거움 | 꿰뚫기 | 틈이 어디에 열리든 **꿰뚫고 들어가** 크게 친다 | 그로기 +30 |
| **C** | 가벼움 | 끊기 | 짧게 자주 **박자를 밀어** 파트너가 받을 시간을 번다 | 그로기 +15 |
| **D** | 가벼움 | 꿰뚫기 | 지나가며 **반대편을 만든다.** 교차 베기의 주인공. 지금 프로토타입의 제비(+꿰뚫기) | 그로기 +15 |

교차 베기 = 두 타격 합계 ×3 + **무너뜨리기(두 사람 기여의 합)**. 무너뜨리기로 그로기가 꽉 차면 그 자리에서 기절(사방이 열림).

## 5. 짝 6가지

| 짝 | 강점 | 약점 | 교차 무너뜨리기 | 이 짝의 순간 |
|---|---|---|---|---|
| A + B (무·무) | 한 방이 크고 같은 박자라 동시가 쉽다 | 멀리 열린 틈을 놓친다. B가 꿰뚫어 메운다 | +60 (바로 기절권) | "같이 휘둘러" |
| A + C (끊·끊) | 공격을 끊고 밀어 시간을 지배 | 자리 문제를 못 푼다. 반대쪽 틈에 약하다 | +45 | C가 박자를 밀고, A가 끊는다 |
| A + D (무·가, 끊·꿰) | **정석.** A가 앞에서 받고 끊고, D가 지나가며 반대편을 만든다 | 동시 맞추기에 무게 차이가 크다 | +45 | D가 꿰뚫는 순간 A가 내려친다 |
| B + C (무·가, 꿰·끊) | C가 시간을 벌면 B가 확실히 꿰뚫어 들어간다 | B의 관통 후 빈틈을 C가 메워야 한다 | +45 | C가 박자를 밀어 B의 0.5초를 만든다 |
| B + D (꿰·꿰) | 어디서든 틈에 닿는다. 교차 베기를 둘 다 만들 수 있다 | 공격을 끊을 사람이 없다. 받기를 더 잘해야 한다 | +45 | 양쪽에서 동시에 꿰뚫고 X자로 빠져나감 |
| C + D (가·가) | 빠르다. 연타와 날아들기로 박자가 촘촘 | 한 방이 약해 그로기를 받기로 채워야 한다 | +30 | 쉬지 않는 랠리 |

- 모든 짝에 "약점을 파트너가 메우는 순간"이 있다 → **실수 메워 주기, 신뢰**.
- 같은 짝도 누가 1P(주황)냐에 따라 색 공격 담당이 바뀐다 → 짝 6 × 자리 2.

## 6. 솔로

- 두 캐릭터를 고르고 태그. 잔상 받기, 스위치(받은 직후 태그), 교차 베기(태그로 들어온 캐릭터와 나간 캐릭터의 타격) 규칙은 같다.
- 솔로에서 꿰뚫기는 특히 강하다(혼자 반대편을 만든다) → 솔로 추천 짝은 A + D, 듀오 추천 짝은 자유.

## 7. 지금 프로토타입과의 차이 (다음 구현 단계 후보)

1. 받기 상성(◆ 내 몫, 판정창·틈·반동 배율) 끄기 → 받기는 모두 같게
2. 제비(D)에 꿰뚫기 추가 (방향은 빠져나간 쪽으로 판정)
3. 교차 베기에 무너뜨리기(무게별 그로기) 추가
4. B, C 추가 (무거운 꿰뚫기, 가벼운 끊기 = 박자 밀기)와 로스터 고르기 화면

## 8. 스킨 (교체 가능, 설계와 무관)

> 사용자 메모: 주인공은 "파동을 해방하기 위한 자들". 몸은 나이트런의 프레이·앤 마이어 같은 결. 무기는 5번검·전자 발도검처럼 특수한 무기.
> 보스와 무대(붉은 디바 → 붉은 기체, 백업 댄서 → 검은 갑주 안무)는 **바이럴용 스킨**이고 판정과 무관.

| 칸 | 스킨 후보 (가안) |
|---|---|
| A 무거운 끊기 | 공명 대검. 모으면 칼날이 울리고, 내려치면 파동을 끊는다 |
| B 무거운 꿰뚫기 | 파일 벙커 창. 말뚝을 박아 넣으며 관통 |
| C 가벼운 끊기 | 전자 발도검. 칼집에 모았다가 발도로 박자를 벤다 |
| D 가벼운 꿰뚫기 | 광선 쌍단검. 잔상을 남기며 꿰뚫어 지나감 |

스킨 교체 시험(우주 해적 / 중세 기사단)으로 보면 네 칸 모두 "큰 칼로 끊기 / 창으로 관통 / 빠른 칼로 끊기 / 단검으로 관통"으로 바뀌어도 성립한다 → 통과.
