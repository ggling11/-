# 알파 · 모비드 메탈 룩 — 자기 프롬프트와 검수 기준

> 사용자 결정 (10월 23일): "이거 느낌 모비드메탈로 갈게."
> - **렌더링: 반실사로 전환** (툰 렌더링 확정 사항을 바꿈)
> - **카메라: 쿼터뷰 유지**
> - **범위: 룩 + 손맛** (판정 규칙은 그대로)
> - **스프링 송 룩: 지운다**
>
> 이 문서는 각 단계에 들어갈 때 다시 읽는 작업 지시서다. 단계마다 통과 기준을 숫자로 재고, 통과하지 못하면 다음 단계로 가지 않는다.
> 레퍼런스: 「Morbid Metal」(Screen Juice / Ubisoft, 2026 앞서 해보기). 스팀 스크린샷 9장과 리뷰를 보고 정리했다.

---

## 0. 공통 규칙

1. **베끼지 않는다.** Flux·Ekku·Vekta·Saru의 얼굴, 갑옷 무늬, 무기 모양, 이름을 옮기지 않는다. "왜 그렇게 보이는가"의 원리만 가져와서 우리 캐릭터(무거움/가벼움/보스)에 맞는 다른 모양으로 푼다.
2. **판정이 먼저다.** 주황 예고(받기 가능), 보라·사선(받기 불가), 흰 받기 링, 금색 틈과 약점은 어떤 연출보다 위에 보여야 한다. 판정 타이밍·거리·크기·충돌 반지름은 바꾸지 않는다.
3. **카메라는 쿼터뷰 그대로.** 모비드 메탈의 낮고 가까운 3인칭 카메라는 가져오지 않는다. 그 대신 쿼터뷰 거리(캐릭터 60~100px)에서 재질·빛·네온이 읽히게 만든다.
4. **손맛은 규칙이 아니다.** 타격 정지, 카메라 반동, 태그 분해 연출, 대시 잔상은 바꿔도 되지만, 판정 창과 게임 시간 흐름은 그대로 둔다. 타격 정지는 게임 시간을 통째로 멈추므로 판정 창의 상대 길이는 변하지 않는다.
5. **금색은 합 전용.** 모비드 메탈은 UI에 노랑·금색을 많이 쓰지만, 이 게임에서 금색은 틈·약점·합에만 쓴다.
6. **움직이는 그림으로 판단한다.** 정지 사진 한 장으로 통과시키지 않는다. 깜빡임·번쩍임은 연속 프레임으로 잰다.
7. **한계는 숨기지 않는다.** 코드로 만든 절차 모델·셰이더의 한계는 문서에 적는다.
8. **기본 룩이 된다.** 새 룩은 타이틀의 첫 화면이다. 다른 레퍼런스 룩 6종과 기본 툰은 비교용으로 남는다.

## 1. 벤치마크 분석 — 모비드 메탈이 화면을 만드는 원리

| 축 | 스크린샷에서 보이는 원리 | 이 게임으로 옮길 원리 (모양은 다르게) |
|---|---|---|
| **실루엣** | 기계 인간. 가는 관절 위에 큰 판, 몸보다 큰 무기 하나, 크게 휘날리는 천 한 장(코트·망토). 머리 모양(볏·삿갓)이 캐릭터마다 완전히 다르다 | 무거움(A·모루) = 넓은 어깨판 + 납작한 넓은 챙 투구 + 큰 망치. 가벼움(D·제비) = 가늘고 긴 몸 + 긴 코트 자락 + 뒤로 뻗은 볏 + 긴 칼. 보스 = 고릴라처럼 앞으로 숙인 덩치 + 아주 큰 주먹 두 개 |
| **재질** | 희고 매끈한 세라믹 장갑판(광택, 가장자리 닳음) + 검은 광택 골격 + 금속 관절. 천은 무광 직물. 배경은 사진 같은 돌·이끼·낙엽·녹슨 쇠 | 캐릭터도 배경도 **반실사 PBR**. 흰 장갑 = 클리어코트 세라믹, 골격 = 검은 반광 금속, 관절 = 짙은 쇠. 외곽선은 쓰지 않는다 |
| **빛과 색** | 따뜻한 노을 역광과 안개, 그 속에서 차가운 네온이 튄다. 캐릭터마다 네온 한 색(눈 틈·칼날·궤적). 적은 빨간 네온 | 해가 화면 위쪽(보스 너머) 낮게 = 역광. 하늘빛 환경 반사로 앞면이 죽지 않게. **네온 = 자리 색**(1P 주황, 2P 파랑), 보스 = 붉은 네온. 블룸은 네온·섬광만(문턱 높게). 색 보정은 밝은 곳 따뜻하게, 그늘 푸르게 |
| **무대** | 자연에 먹힌 동아시아풍 폐허(기와 지붕, 돌계단, 단풍) + 거대한 기계 구조물(고리 모양 아치, 바닥을 기는 케이블) | 무너진 사찰 마당 + 뒤쪽의 거대한 고리 구조물 + 마당 가장자리를 기는 케이블 + 이끼 낀 기계 잔해. 낙엽이 바닥과 공중에 |
| **모션** | 빠르고 끊어 치는 동작, 회피는 빛줄기를 남긴다, 콤보 중에도 캐릭터를 바꾼다 | 기존 IK·스프링·천 체계를 그대로 쓰고, 대시와 회피에 자리 색 빛줄기를 남긴다 |
| **이펙트** | 네온 참격 호, 작은 사각 입자(데이터 조각), 홀로그램 다각형 조각, 세로 빛기둥, 주황 폭발과 불티, 가장자리의 색 갈라짐 | 받기 = 흰 섬광 + 불꽃. 합 = 금빛 섬광 + 홀로그램 조각 + 데이터 입자. **약점이 열리면 장갑판이 깨져 떨어지고, 합을 맞으면 약점이 터진다.** 태그 = 나가는 캐릭터가 자리 색 입자로 흩어지고 들어오는 캐릭터가 입자에서 맞춰진다 |
| **약점 표시** | Saru의 주먹 둘레에 뜨는 주황 표적 고리(두 겹, 바깥이 번짐). 그 부위를 치면 다음 공격이 약해진다 | 틈이 열리면 약점 자리에 **금색 표적 고리**(두 겹 + 도는 눈금)가 카메라를 보고 뜬다. 고리 크기와 위치는 기존 약점 판정과 같다 |

손맛에서 가져오지 않는 것: 스타일 등급(A·4x 같은 점수). 혼자 잘하는 보상이 되고, "UI 최소화·숫자보다 느낌" 원칙과 맞지 않는다.

## 2. 단계별 프롬프트

각 단계는 **① 목표 ② 만들 것 ③ 하지 말 것 ④ 통과 기준(측정) ⑤ 검수 방법**. 통과하면 커밋.

### 단계 0 — 스프링 송 걷어 내기와 새 룩 자리
- 목표: 스프링 송 룩을 지우고, 그 룩이 쓰던 범용 장치(반실사 배경 질감 생성, 뼈대 모델, 2관절 IK, 스프링 자세, 베를레 천, 불꽃·섬광)를 새 룩의 장치로 옮긴다.
- 만들 것: 룩 목록에서 스프링 송 삭제, 달밤 하늘·검은 진흙·붉은 맥 셰이더 삭제, 장치 이름을 `hf*` → `mm*`로, 새 룩 「모비드 메탈」을 기본 룩으로.
- 하지 말 것: 다른 룩 6종과 기본 툰을 깨기.
- **통과 기준**: `load.mjs` 오류 0, `smoke.mjs` 통과, 코드에 "스프링 송" 룩 항목 0.

### 단계 1 — 반실사 렌더링 바탕
- 목표: 같은 장면이 "그림"이 아니라 "빛을 받는 물체"로 보인다.
- 만들 것: 노을 하늘 환경 반사(PMREM), ACES 톤 매핑(후처리 합성에서), 노출, 그림자, 문턱 높은 블룸, 따뜻한 밝은 곳 / 푸른 그늘 색 보정, 거리 기준 안개.
- 하지 말 것: 매 프레임 바뀌는 굵은 필름 입자, 빠르게 떨리는 빛.
- **통과 기준**: `flicker.mjs` 전역 밝기 진동 < 0.6, 깜빡이는 픽셀 < 1.5%, 되돌이 < 0.5%.

### 단계 2 — 무대: 노을 속 무너진 사찰 마당
- 목표: "어디서 싸우는가"가 한눈에. 자연에 먹힌 폐허 + 거대한 기계 구조물.
- 만들 것: 마른 판석 마당(이끼·낙엽), 무너진 돌난간과 석등, 화면 위쪽의 축대·돌계단·문(두 기둥 + 위로 휜 두 겹 가로대), 안개 속 기와 지붕 실루엣, 뒤쪽의 거대한 고리 아치(차가운 네온 띠), 가장자리를 기는 케이블, 이끼 낀 기계 잔해, 단풍과 짙은 나무, 공중의 낙엽과 먼지, 빛줄기.
- 하지 말 것: 떠 있는 원판, 아래가 보이는 허공, 마당 안쪽을 어지럽히는 소품.
- **통과 기준**: `world.mjs` 1280×720·400×800·960×540 모두 허공 0/24, 예고 테두리 대비 ≥ 3:1.

### 단계 3 — 캐릭터: 흰 장갑의 기계 인간
- 목표: 기본 도형이 아니라 설계된 실루엣 + 반실사 재질.
- 만들 것: 모루(넓은 흰 어깨판, 납작한 넓은 챙 투구, 자리 색 눈 틈, 짧은 직물 망토, 네온 날이 선 큰 망치), 제비(가늘고 긴 검은 골격, 흰 긴 코트 자락 두 장, 뒤로 뻗은 흰 볏, 자리 색 눈 틈과 칼날), 보스(앞으로 숙인 덩치, 흰·붉은 장갑판, 아주 큰 주먹과 붉은 네온 마디, 붉은 눈 틈). 기존 root/tilt/spin/arm 묶음에 붙인다.
- 하지 말 것: 레퍼런스 캐릭터의 고유 디자인 재현. 외곽선.
- **통과 기준**: `models.mjs` 실루엣 IoU 0.6 미만(셋 모두), 자리 색이 몸의 네온으로 남음, 충돌 반지름 불변.

### 단계 4 — 손맛
- 목표: 끊어 치는 맛과 캐릭터 교대의 쾌감.
- 만들 것: 일반 타격의 짧은 타격 정지(0.035초)와 카메라 반동, 대시·회피의 자리 색 빛줄기, 태그 분해(나가는 캐릭터가 자리 색 사각 입자로 흩어짐) + 맞춰짐(들어오는 캐릭터가 아래에서 위로 0.14초 만에 맞춰짐).
- 하지 말 것: 판정 창 바꾸기, 들어오는 캐릭터를 늦게 보이게 해서 태그 진입 공격을 가리기.
- **통과 기준**: `smoke.mjs` 통과(판정 타이밍 불변), `motion.mjs` 천 파고듦 0·NaN 0, `strobe.mjs` 번쩍임 0.

### 단계 5 — 이펙트: 약점이 터진다
- 목표: 틈 = 장갑이 깨져 약점이 드러남, 합 = 약점이 터짐.
- 만들 것: 틈이 열릴 때 약점 자리에서 흰 장갑 조각이 튀고 금색 표적 고리가 들어옴. 합 = 금빛 섬광 + 홀로그램 다각형 조각 + 데이터 입자 + 충격파. 완벽한 합 = 정지 동안 조각이 멈췄다가 풀리며 세로 빛기둥. 자리 색 네온 칼 궤적과 그 위의 데이터 입자. 보스 주먹의 붉은 네온 궤적.
- **통과 기준**: `occlude.mjs` 판정 표시를 절반 넘게 가린 시간 < 0.25초, `fxshots.mjs` 섬광(화면 평균 휘도가 최고치 절반 넘는 시간) < 0.1초.

### 단계 6 — 종합 검수
- 모든 검사를 한 번에 다시 돌리고, 레퍼런스 스크린샷과 나란히 놓고 본다.
- **통과 기준**: 단계 0~5 기준 모두 + 폰 폭 가로 스크롤 없음 + 그리기 호출 수 기록.

## 4. 단계별 결과 (측정값)

### 단계 0 — 스프링 송 걷어 내기 (통과)
- 룩 목록·달밤 하늘(하늘 모드 5·6)·검은 진흙·붉은 맥 셰이더·칼 참격(MMSlash)·보스 검은 연기를 지웠다. 툰 셰이더에서 스프링 송 전용 맥·금속 줄도 뺐다.
- 범용 장치는 이름만 바꿔 이어받았다: 배경 질감 생성(판석·마당·마름돌·바위), 뼈대 모델 도우미, 2관절 IK, 스프링 자세, 베를레 천·사슬, 불꽃·섬광, 잔상. `springsong.mjs` → `morbid.mjs`.
- 기본 룩 = 모비드 메탈 (타이틀 화면 고르기의 첫 칸, `H`로 바꾼다).

### 단계 1 — 반실사 렌더링 바탕 (통과)
- 합성 셰이더에 ACES 톤 매핑(three.js와 같은 식, 노출 1.08). 후처리를 끈 화면은 렌더러의 ACES로 같은 톤.
- 노을 하늘을 PMREM 환경 반사로: 위는 푸른 남색, 지평은 살구빛, 해 쪽은 금빛. 해는 보스 너머 오른쪽 위 약 33°.
- 블룸 문턱 2.0: 해를 받은 흰 장갑(약 1.2)은 번지지 않고 네온(4)·섬광만 번진다. 처음엔 문턱 1.1이라 보스가 하얗게 탔다.
- 돌 질감이 달밤용으로 너무 어두웠다(알베도 약 0.06) → 마른 사암빛 회색으로 다시 칠했다.
- `flicker.mjs`: 모비드 메탈 glob 0.009 · jump 0.046% · back 0.003% (기준 0.6 · 1.5% · 0.5% 통과, 평균 휘도 86). 기본 툰 0.002 · 0.001% · 0%.

### 단계 2 — 무대 (통과, 대비는 아래 메모)
- 만든 것: 마른 판석 마당과 바깥 판석, 무너진 돌난간, 석등 4, 축대·돌계단, 바랜 주칠 문(두 기둥 + 위로 휜 가로대), 기와 전각 2채와 4층 탑, 거대한 기계 고리(흰 장갑판 44장, 끊긴 청록 네온 9토막, 늘어진 케이블), 마당 가장자리 케이블 7가닥, 쇠 바닥판, 흩어진 장갑 조각, 반쯤 묻힌 거대한 머리와 손, 단풍·상록수, 바닥 낙엽 1,500장, 떨어지는 잎 70장, 빛줄기 5줄, 노을 안개.
- 쿼터뷰 카메라는 위쪽 끝이 보스 너머 약 25m에서 땅에 닿는다. 그래서 전각·탑·고리는 플레이 화면 밖이고, 다시 보기 카메라와 넓은 화면에서만 보인다. 플레이 화면의 모비드 메탈다움은 마당 둘레(빛, 쇠판, 케이블, 잔해, 낙엽)와 캐릭터가 맡는다.
- `world.mjs` (예비 동작 70% 정지 장면):

| 화면 | 허공(가장자리 24곳) | 테두리 : 바로 바깥 | : 바깥 바닥 | 그리기 호출 |

| 1280×720 | 0 | 4.29 : 1 | 2.47 : 1 | 351 |
| 400×800 | 0 | 4.39 : 1 | 2.39 : 1 | 352 |

- 대비 메모: 해가 든 돌바닥(휘도 0.18)이 스프링 송의 달밤 바닥(약 0.09)보다 두 배 밝아서, 바깥 바닥과의 대비가 스프링 송(3.78 : 1)보다 낮다. 이 룩에서만 예고 테두리를 1.8배 밝게 해서 1.87 → 2.47로 올렸다(블룸 문턱 아래). 테두리 바로 바깥의 어두운 띠가 4.3 : 1로 테두리를 세운다.

### 단계 3 — 캐릭터 (통과)
- 재질: 흰 세라믹(클리어코트, 면이 각지게 끊어지는 플랫 셰이딩), 검은 골격(반광 금속), 쇠 관절, 직물(광택 sheen), 자리 색 칠, 네온(HDR 4). 외곽선 없음.
- 보스: 앞으로 숙인 고릴라형. 팔각 가슴통, 육각 어깨판, 배의 붉은 네온 세 줄, 등 혹의 주황 배기구, 작고 낮은 머리(눈은 기존 보스 눈 재질: 금 → 주황 깜빡임), 아주 큰 주먹(쇠 마디 넷 + 붉은 네온 마디). 칠 판 색은 보스 종류마다(문지기 진홍, 늙은 중 구리, 되받이 청록).
- 모루: 납작하고 넓은 흰 챙 투구(위에서 보면 이 원이 모루), 앞만 덮는 흰 가슴판, 각진 어깨판, 직물 망토, 네온 테가 선 망치.
- 제비: 가늘고 긴 검은 골격, 흰 긴 코트 자락 두 장(베를레), 뒤로 뻗은 흰 볏 세 장, 자리 색 천 두 갈래, 날을 따라 도는 네온 선.
- 처음 모델은 둥근 흰 덩어리(마시멜로처럼)였다 → 팔각·육각 단면 + 플랫 셰이딩으로 장갑을 끊고, 모루는 흰 면적을 줄여 검은 골격을 드러냈다.
- `models.mjs`: 실루엣 IoU 보스-1P 0.58 · 보스-2P 0.27 · 1P-2P 0.39 (0.6 미만 통과). 그리기 306회.

### 단계 4 — 손맛 (통과)
- 일반 타격: 게임 시간을 통째로 0.035초 멈춘다(크게 당긴 타격은 0.055초) + 카메라 흔들림 0.16. 타격점에서 공격자 자리 색 데이터 조각이 튄다. 타격 정지는 게임 시간 전체를 멈추므로 판정 창의 상대 길이는 그대로다.
- 태그: 나가는 캐릭터는 몸 겉면에서 고른 70점이 자리 색 사각 입자로 흩어지고 옅은 잔상이 남는다. 들어오는 캐릭터는 0.14초 동안 발에서 머리로 맞춰진다(맞춰지는 선이 자리 색으로 빛난다). 태그 진입 공격은 처음부터 판정이 살아 있고, 무기 높이까지는 0.06초 안에 맞춰진다.
- 빠른 이동·회피: 자리 색 잔상.
- `smoke.mjs` 통과. 규칙 검사는 기본 툰에서 그대로 돌리고, 모비드 메탈 검사를 따로 더했다: 두 명 받기 → 틈·표적 고리·두 캐릭터 모델 켜짐, 합 1 / 혼자 받기 → 태그 → 맞춰지기 시작·나간 캐릭터 숨김 → 합 1 → 맞춤 끝. 반실사 화면은 소프트웨어 렌더링에서 한 장 찍는 데 30초를 넘길 때가 있어서 검사 대기 시간을 120초로 늘렸다(판정과는 상관없음).
- `strobe.mjs` (10초, 600프레임): 번쩍임 **0**, 섬광 2번, 화면 평균 휘도 84~146.
- `motion.mjs`: 처음엔 **불통과**: 제비 코트 자락 끝 한 점이 정강이 캡슐 안으로 0.5cm(반지름의 6%) 들어갔다. 자락(1.05m)이 쉼 자세에서 이미 땅 아래까지 내려와서, 몸 밖으로 민 뒤에 하는 땅 고정(3cm)이 자락 끝을 발목 캡슐 끝 안으로 다시 밀어 넣었다. 고친 것: 자락을 0.92m로 줄이고(쉼 자세에서 발목 위 9cm, 끌리지 않는다), 밀기 순서를 땅 → 몸으로 바꿨다(세 번 되풀이, 마지막은 몸 밖으로). 다시 잼: 천 파고듦 **0** (가장 깊이 0.0cm), 뼈 NaN **0**.

### 단계 5 — 이펙트 (통과, 섬광 측정 메모)
- 틈: 약점 자리에서 흰 장갑 파편이 틈 방향으로 튀고, 금빛 표적 고리(바깥 고리 + 번짐 + 도는 안쪽 호 넷과 눈금 + 팔면체 핵)가 카메라를 보고 뜬다. 고리 크기·위치는 기존 약점 판정과 같다.
- 합: 금빛 섬광 + 홀로그램 다각형 조각(선만, 0.55~0.9초) + 데이터 입자 + 충격파 + 흰 장갑 파편 + 먼지. 완벽한 합은 정지 동안 조각이 멈춰 있다가 풀리며 세로 빛줄기 6개가 선다.
- 휘두르기: 자리 색 네온 칼 궤적 + 날 끝에서 떨어지는 데이터 조각. 보스 주먹: 붉은 네온 궤적.
- `occlude.mjs` (자동 관람 20초): 판정 표시를 절반 넘게 가린 가장 긴 시간 예고 원 **0.000초** · 받기 고리 **0.000초** (기준 0.25초 미만). 본 프레임: 예고 65, 고리 4.
- `fxshots.mjs`: 받기 섬광 **0.050초**, 합 섬광 **0.067초** (기준 0.1초 이내).
  - 메모: 화면 전체 휘도로 재면 합은 0.38~0.55초가 나온다. 반실사 화면은 바탕이 밝아서(평균 휘도 110) 합의 최고치가 바탕보다 5.7밖에 오르지 않는데, 그 절반(2.9)은 오래 남는 홀로그램 조각만으로도 넘는다. 그래서 `fxshots.mjs`에 '섬광만' 측정을 더했다: 같은 이펙트를 한 번 더 터뜨리고 오래 남는 층(홀로그램 조각, 데이터 입자, 불티, 먼지, 김, 파편)을 그리지 않은 채 휘도만 잰다. 위 0.067초가 그 값이다. 연속 사진에서도 흰 섬광은 0.1초 칸에서 이미 사라지고 0.2~0.35초 칸에는 금빛 선 조각만 남는다.
  - 내려찍기 0.63초는 섬광이 아니라 천천히 퍼지는 김과 먼지다(스프링 송 때 0.67초와 같은 이유).
