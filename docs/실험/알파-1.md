# 알파-1 — 합 다음에 무엇이 이어지는가

출발점: 공격과 보상 (연계, 게이지, 필살기, 콤보 구조).
프로토타입 링크 (알파-1): https://claude.ai/artifact/LiVjSob4EbV49JryRYZAGw
지금 프로토타입의 루프는 **받기 → 틈 → 합**에서 끝난다. 합이 터지면 보스가 휘청이고, 받은 사람은 반동이 풀린 뒤 할 일이 없다.
이 세션은 "합이 끝이 아니라 **다음 박자를 부르는** 구조"를 찾는다.

---

## 2. 채택 A — 맺기 (3박 연계: 받기 → 합 → 맺기)

### 한 문장
**합을 맞은 보스는 받은 사람 쪽으로 휘청인다. 판을 깐 사람이 판을 닫는다.**

### 규칙
1. 합이 터지면 보스는 휘청이고, **받은 사람 쪽(합이 들어온 반대편)에 맺기 틈**이 열린다 (청록색, 금색 틈과 구분)
2. 받은 사람이 그 틈을 치면 **맺기**: 피해 ×2.5, 휘청임 +0.5초, 기세 +16
3. 맺기 틈은 합 후 1.3초. 이 동안 보스 휘청임이 보장된다
4. 맺기는 **보스 시선을 빼앗지 않는다** → 합을 친 사람에게 넘어간 시선은 그대로. 역할 교대가 깨지지 않는다
5. 반동 중에 공격을 눌러 두면 반동이 풀리는 순간 나간다 (선입력). 반동은 "못 친다"가 아니라 **"아직 못 친다"** 가 된다

### 왜 이게 "합 다음"인가
- 지금은 받은 사람이 판을 깔고 끝. 받는 쪽이 **조연**으로 느껴질 위험이 기획서에 이미 적혀 있다 → 맺기가 그 답
- 합의 물리가 그대로 이어진다: 파트너가 등을 쳤으니 보스는 앞으로(받은 사람 쪽으로) 쏠린다. 규칙이 아니라 **몸과 공간**이 이유
- 소리도 이어진다: 합의 도·미·솔 화음을 맺기가 **한 옥타브 위에서 받아 닫는다**. 두 사람이 한 마디를 같이 연주하는 느낌

### 감정
| 감정 | 맺기에서 생기는 순간 |
|---|---|
| 1. 합의 쾌감 | 합이 한 번 터지고 끝나는 게 아니라, **두 번째 화음**이 붙는다. 3박이 맞아떨어지는 쾌감 |
| 2. 신뢰 | 받은 사람은 반동 중에 이미 공격을 눌러 둔다 = "쟤가 합 넣을 거야"를 믿고 미리 준비 |
| 4. 찬스 만들고 끝내 주기 | 받은 사람이 열고, 파트너가 터뜨리고, 받은 사람이 닫는다 |
| 4. 역할 교대 | 시선은 합을 친 사람에게. 다음 받기는 그 사람 몫 |

### 솔로 / 듀오
- **듀오**: 받기(1P) → 합(2P) → 맺기(1P). 반동 선입력이 있어 "합 소리 듣고 바로 치기"로 충분
- **솔로**: 받기(A) → `Q` 합(B 태그 진입) → `Q` 맺기(A 태그 진입). **받기-태그-태그** 한 손 리듬. 맺기 태그는 태그 쿨타임 무시
- **혼자 듀오 연습**: 합 후 `Q`로 A에게 넘겨 `F`

## 3. 채택 B — 기세 → 합기

### 한 문장
**둘이 함께 쌓은 기세가 가득 찰 때, 완벽한 합은 합기가 된다.**

### 규칙
- 기세는 **하나뿐인 공동 게이지** (보스 체력 바 아래)
- 쌓임: 받기 +4 / 정확한 받기 +8 / 합 +18 / 완벽한 합 +26 / 맺기 +16
- 깎임: 틈 놓침 −15 / 정통으로 맞음 −10 (버티기 피해는 깎지 않음)
- 가득 차면 게이지가 금색으로 맥박치고 "기세 가득 · 완벽한 합으로 합기"
- 가득 찬 상태에서 **완벽한 합**이 들어가면 **합기**: 피해 ×8, 긴 히트스톱·슬로모션·큰 링, 휘청임 2.2초, 기세 0으로
  - 합기 순간 받은 사람의 반동이 즉시 풀린다 → **합기 → 맺기**까지 이어 갈 수 있다
- 일반 합은 기세를 소모하지 않는다 (조정 패널에서 "합기는 완벽한 합만"을 끄면 일반 합도 합기)

### 왜 동시 버튼이 아니라 "다음 완벽한 합"인가
- 합기를 따로 발동하는 버튼이 있으면 받기와 틈 바깥의 컷신이 된다
- "기세가 찼다 → 이번엔 완벽하게 맞추자"는 **파트너가 받기 전에 미리 휘두르는 신뢰**(우선순위 2)를 가장 강하게 요구한다
- 게이지는 혼자 못 채운다. 받기만 해도, 합만 해도 느리다. **3박을 다 맞춰야 빨리 찬다**

### 감정
| 감정 | 기세/합기에서 생기는 순간 |
|---|---|
| 1. 합의 쾌감 | 쌓아 온 것이 한 번에 터진다. 일반 합과 완벽히 구분되는 최상위 등급 |
| 2. 신뢰 | 가득 찬 뒤의 받기: "이번엔 진짜 미리 휘둘러야 한다" |
| 3. 내 거 / 네 거 | 기세가 찼을 때 누가 받을지가 더 무거워진다 (덤) |
| 4. 실수 메워 주기 | 피격과 놓친 틈이 **둘의** 기세를 깎는다 → 실수가 공동의 아쉬움이 된다 |

## 4. 두 시스템의 관계

```
받기 ──▶ 합 ──▶ 맺기          (한 번의 교환 = 3박)
  +4~8    +18~26   +16        → 기세
                               가득 차면
받기 ──▶ 완벽한 합 = 합기 ──▶ 맺기   (클라이맥스)
```

맺기가 **한 교환의 끝**을 만들고, 기세가 **교환과 교환 사이의 흐름**을 만든다.
둘 다 받기와 틈 위에서만 일어나고, 새 버튼이 없다.

## 6. 확인해 줘야 할 것 (사용자)

1. **3박이 길게 느껴지는가, 맛있게 느껴지는가?** 합에서 끝나는 게 더 깔끔하다면 맺기 시간을 줄이거나 끄면 된다
2. **맺기 배율 ×2.5가 합(×2)보다 커도 되는가?** 받은 사람이 주인공이 되는 대신 합의 무게가 줄어 보일 수 있다
3. **솔로의 "받기 → Q → Q"** 가 태그 액션 손맛으로 괜찮은가 (젠존제 연계기와 비슷한 감각을 노림)
4. 합기 조건: **완벽한 합만** vs **아무 합이나**. 지금은 완벽한 합만 (신뢰를 강하게 요구)
5. 기세가 **피격으로 깎이는 것**이 벌칙처럼 느껴지는가, 공동의 아쉬움으로 느껴지는가

## 7. 다른 세션과 합칠 때

- 보스 패턴 세션(B)의 **연속 공격**, **동시 공격(맞받기)** 과 잘 맞는다: 맞받기 틈은 받은 사람이 둘이라 맺기가 열리지 않는다 → 동시 공격 전용 합기(둘 다 맺기)를 따로 설계할 여지
- 캐릭터 세션(D)의 **태그 연계기**는 솔로 맺기 태그(`Q` 두 번째)에 캐릭터별 모션을 입히는 자리
- 연출 세션(A)은 합 / 맺기 / 합기 3단 연출 위계를 쓰면 된다
