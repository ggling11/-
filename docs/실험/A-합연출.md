# A. "와"를 만드는 합 연출

브랜치 `claude/dazzling-cori-t72jor` · 프로토타입 `prototype/index.html` · 게시 링크는 이 문서 맨 아래.

## 한 줄 방향
**합은 세계 안에서 터지고, 완벽한 합은 화면 전체가 멈췄다가 터진다.**
합과 완벽한 합은 "더 큰 같은 연출"이 아니라 **다른 종류의 사건**으로 느껴져야 한다.
합 = 좋은 타격. 완벽한 합 = 시간이 멈추는 순간.

## 설계 원칙
1. **멈춤 → 터짐**. "와"는 터지는 순간이 아니라 *멈췄다 풀리는 순간*에 나온다. 정지 동안 긴장을 쌓고, 풀릴 때 소리·충격파·빛을 한꺼번에 놓는다.
2. **두 사람을 한 프레임에**. 완벽한 합의 주인공은 친 사람이 아니라 *둘*이다. 카메라는 받은 사람·친 사람·약점의 무게중심으로 다가가서 둘 다 화면에 담는다.
3. **소리가 타이밍을 말해 준다**. 캐릭터마다 자기 음이 있다 (A·1P = 도, B·2P = 솔). 받기는 받은 사람의 음, 합은 친 사람의 음. 늦게 치면 두 음이 *따로* 들리고, 동시에 치면 한 *화음*(완전5도)이 된다. 숫자 없이 "얼마나 맞았는지"를 귀로 안다. 기획서의 "두 음이 겹치는 화음 같은 타격음"을 그대로 규칙으로 만든 것.
4. **신뢰를 이름으로 불러 준다**. 받기 *전에* 먼저 들어간 완벽한 합(preHap)은 도장 아래에 "믿고 먼저 휘둘렀다"가 붙는다. 우선순위 2(신뢰)를 연출이 알아봐 준다.
5. UI 숫자는 최소화. 완벽한 합에서는 배율 숫자를 지웠다.

## 3단 사다리

| | 일반 타격 | 합 | 완벽한 합 |
|---|---|---|---|
| 정지 | 없음 | 0.07~0.13초 (완벽에 가까울수록 길게) | **0.3초**, 파티클·자세까지 전부 멈춤 |
| 첫 순간 | 흰 불꽃 | 금색 툰 별 + 금색 파편 | **흑백 임팩트 프레임 2장** (흰 바탕 검은 실루엣 → 검은 바탕 금빛 실루엣) |
| 카메라 | 그대로 | 약점 쪽으로 살짝 당김 | 두 사람+약점으로 확 다가가고 살짝 기울어짐(롤), 슬로모션과 함께 천천히 빠짐 |
| 화면 | – | 약한 섬광 | 집중선, 레터박스, 배경 어두워짐(캐릭터만 남음), HUD 숨김 |
| 글자 | 숫자 | 세계 위에 "합!", 아까우면 "아깝다 · 0.08초 늦음" | 화면 중앙 도장 "완벽한 합" + 금색 붓 띠, 아래에 "동시에" / "믿고 먼저 휘둘렀다" |
| 소리 | 타격음 | 친 사람의 음 (받기 음과 시차를 두고) + 저음 | 정지: 균열음 + 저음 낙하, 전체가 물속처럼 먹먹해지고 두 음만 높게 운다 → 풀림: 두 음을 포함한 화음이 잔향과 함께 터짐 |
| 풀릴 때 | – | – | 충격파 3겹(금/흰/검은 선), 빛기둥, 파편, 0.2배속에서 1배로 0.9초 동안 복귀, 두 사람에게 금빛 잔상 |
| 보스 | 흰 번쩍 | 찌그러졌다 출렁 (약하게) | 찌그러진 채 멈췄다가 크게 출렁 |
| 패드 진동 | – | 짧고 가볍게 | 정지 내내 강하게 + 풀릴 때 한 번 더. **두 패드가 같이 울린다** |

- 합의 강도는 "완벽한 합에서 얼마나 멀었나"로 연속적으로 변한다. 아깝게 놓친 합은 거의 완벽한 합처럼 커진다 → "조금만 더 빨리"를 몸으로 배운다.
- 받기 자체도 소리를 낸다. 정확한 받기는 종소리(받은 사람 음의 한 옥타브 위), 버티기는 부드러운 삼각파. 받는 사람이 화음의 첫 음을 낸다 = 받는 사람도 주인공.

## 합 연출 보기 (자동 관람 모드)
사용자가 모바일이라 직접 쳐 볼 수 없어서 넣었다. 타이틀의 **합 연출 보기**(4번)를 누르면 AI 둘이 계속 아래를 반복한다.
1. **합** — 받기를 보고 나서 0.75초 뒤에 친다 (두 음이 따로)
2. **완벽한 합** — 받기와 동시에 친다 (한 화음)
3. **완벽한 합 · 믿고 먼저** — 받기 성공 전에 이미 휘두른다

합을 친 사람이 다음에 노려지므로 역할이 저절로 바뀌는 것도 같이 보인다.
오른쪽 아래 버튼: **연출: 새 연출 ↔ 기존** (같은 장면을 이전 연출과 비교), **속도 1배/0.5배/0.25배**, **나가기**. 이 버튼들은 메뉴 조작이지 터치 게임 조작이 아니다.

## 조정 패널 (` 키) → "합 연출" 폴더
연출(새/기존), 완벽한 합 정지 시간, 정지 후 슬로모션 시작 배속, 슬로모션 복귀 시간, 정지 중 카메라 거리, 흑백 임팩트 프레임 / 집중선 / 레터박스 / 패드 진동 켜고 끄기.
`prefers-reduced-motion`이면 임팩트 프레임·카메라 롤을 끄고 흔들림을 줄인다.

## 그 밖에 바뀐 것
- 세로 화면(폰)에서 카메라가 조금 물러나서 아레나가 잘리지 않는다 (모든 모드).
- 스모크 테스트에 관람 모드 검사 추가: 합 1번 이상, 완벽한 합 정지 화면(레터박스·도장), 완벽한 합 2번 이상(믿고 먼저 포함), 기존 연출로 바꿔도 오류 없음.

## 아직 확인 못 한 것 / 판단이 필요한 것
- **정지 0.3초가 너무 긴가?** 액션 게임 기준으로는 길다. 대신 완벽한 합은 한 판에 몇 번 안 나오는 사건이라는 가정. 보스 공격 템포가 빨라지면 0.2초 정도로 줄이는 게 맞을 수 있다.
- **흑백 임팩트 프레임은 번쩍임이 강하다.** 애니 연출 느낌을 위해 넣었지만 호불호가 갈린다. 끄고 켜며 비교 필요.
- **완벽한 합이 너무 자주 나오면 사건이 아니게 된다.** 지금 테스트용 판정(받기 후 0.25초 + 받기 전 0.12초)이 넉넉하다. 연출 강도와 판정 폭은 같이 조정해야 한다.
- 음 체계(캐릭터마다 자기 음)는 캐릭터 설계(D 세션)와 맞물린다. 캐릭터가 늘어나면 어떤 둘을 골라도 화음이 되게 음을 정해야 한다 (예: 모두 같은 5음 음계 안에서).
- 실제 손맛은 헤드리스 테스트로 확인할 수 없다. 관람 모드로 먼저 보고, 패드로 쳐 볼 것.

## 다른 세션과 합친 것
이 브랜치에는 알파·알파-1·E 세션도 푸시해서, 덮어쓰지 않고 병합했다.
- 브랜치의 `prototype/index.html`은 **알파(충격·끼어들기) + 알파-1(맺기·기세·합기) + 알파-2(시선과 노림) + D(캐릭터 모루·제비) + A(합 연출)** 가 함께 들어간 상태다.
- 알파-2의 노림은 두 연출 모두에서 실린다. 새 연출에서는 노림만큼 정지가 길어지고 "노림 N%"만 작게 뜬다(배율 숫자는 숨김).
- 알파-1의 **합기**는 새 연출에서 완벽한 합 시네마틱을 그대로 쓰고, 도장 글자가 "합기 / 둘이 모은 기세"로 바뀌며 정지가 0.12초 길고 맺기 색 충격파가 한 겹 더 퍼진다. "기존" 연출을 고르면 알파-1이 만든 합기 연출이 그대로 나온다.
- 위 게시 링크는 **A만 들어간 버전**(병합 전)이다. 연출만 따로 비교하기 쉽게 그대로 둔다.
