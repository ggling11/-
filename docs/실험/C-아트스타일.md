# 실험 C — 아트 스타일 탐색

> 세션 C 결과. 아직 **결정이 아니라 비교 자료**다. 고른 방향은 사용자 확인 뒤 `docs/기획서.md`의 "비주얼"에 옮긴다.

- 비교 화면: `prototype/art-lab.html` (게시 링크는 아래 "링크")
- 테스트: `cd prototype/test && npm install && node art.mjs` → `prototype/test/out/art_*.png`
- 게임 본체(`prototype/index.html`)는 **건드리지 않았다.** 다른 세션과 합칠 때 충돌이 없게 하려고 따로 만들었다.

## 무엇을 만들었나

**같은 7초짜리 장면을 일곱 스타일로 동시에 재생하는 비교판.** 모든 칸이 같은 시간에 맞춰 움직인다.

| 시간(초) | 장면 | 무엇을 보려고 |
|---|---|---|
| 0.4 ~ 1.6 | 보스 내려찍기 예비 동작, 주황 예고 원이 차오름. 1P는 1.2초부터 받기 자세 | 예고 색이 바닥에서 읽히는가, 받기 자세가 보이는가 |
| 1.48 | 2P가 **받기 전에 먼저** 휘두르기 시작 (신뢰) | 치는 쪽 동작이 보스 너머에서 읽히는가 |
| 1.6 | 정확한 받기, 틈(금색 부채꼴)이 2P 쪽으로 열림 | 틈이 "반대편"이라는 게 한눈에 보이는가 |
| 1.66 | **완벽한 합**: 0.22초 히트스톱 + 0.3초 슬로모션, 두 사람과 약점이 금빛 선으로 이어짐 | 스타일마다 "와"가 어떻게 달라지는가 |
| 2.66 ~ 3.0 | 보스가 2P 쪽으로 돌아섬 (시선 교대) | 노려지는 표시가 읽히는가 |
| 3.0 ~ 4.1 | 충격파 예비 동작 (보라 + 사선 = 받기 불가) | 받기 가능/불가 구분이 색 없이도 되는가 |
| 4.1 ~ | 충격파, 둘 다 회피 | 큰 효과가 캐릭터를 가리지 않는가 |

조작:
- **모아 보기 / 하나씩**: 칸을 누르면 그 스타일을 크게 보고 설명을 읽는다. 폰에서는 좌우로 밀어서 넘긴다.
- **순간 고정**: 예비 동작 / 완벽한 합 / 충격파. 시간 막대로 직접 끌 수도 있다.
- **캐릭터: 지금 캡슐 / 실루엣 제안**
- **검사: 명도** (흑백으로 바꿔 색 없이 읽히는지) / **실루엣** (모아 보기에서는 지금·제안 × 세 순간을 검은 모양으로 비교)

## 일곱 방향

| # | 이름 | 한 줄 | 합 연출 | 감정과 연결 | 가장 큰 위험 |
|---|---|---|---|---|---|
| 0 | **기준** | 지금 프로토타입 그대로 | 금색 원형 플래시 | (비교 기준) | 정체성 약함, 회색 그림자가 탁함 |
| 1 | **밤마당** · 목판 횃불 (E 세계관 맞춤) | 밤 남색 + 횃불 주황 림, 그림자에 해칭, 굵고 고르지 않은 남먹 외곽선, 다진 흙 마당 + 횃불 빛 웅덩이. 보스는 오방색(청·적·백·흑) 포인트 | 0.1초 목판 반전 프레임 → 금빛 번짐 | 어둠 속 횃불 림으로 두 사람 윤곽이 살아남(신뢰), 반전 프레임(쾌감) | 횃불·1P·받기 예고가 모두 주황 계열 |
| 2 | **셀 애니** · 한낮의 결투장 | 2단 명암, 차가운 색 그림자, 흰 역광 테두리, 하이라이트 띠 | 방사형 집중선 + 흰 번쩍임 | 1순위 쾌감을 "컷인" 문법으로 바로 줌 | 레퍼런스(젠존제·명조)와 너무 닮음 |
| 3 | **먹선** · 한지 위의 결투 | 한지 + 먹. 색은 두 사람(인주 주홍, 쪽빛)과 금박에만 | 0.1초 흑백 반전 프레임 → 바닥에 먹 튐 | 색이 귀해서 두 색이 금으로 이어지는 합이 가장 극적 | 동양풍 세계관으로 강하게 묶임, 해칭이 화면에 붙어 미끄러져 보임 |
| 4 | **네온** · 자정의 결투장 | 몸은 어둡게, 테두리와 외곽선을 자기 색으로 발광, 빛나는 격자 바닥 | 금빛 과노출 + 블룸 확장 | 어둠 속 파트너의 빛 = 등을 맡기는 신뢰(2순위) | 어두운 보스 몸 → 예비 동작 자세가 덜 읽힘 |
| 5 | **구아슈** · 해 질 녘 숲속 공터 | 부드러운 3단, 라벤더 그림자, 노을 림, 종이 결 | 따뜻한 빛 번짐 + 꽃잎 | "좋다"에 가까운 따뜻함 (신뢰, 메워 주기) | 1순위 쾌감이 약함 |
| 6 | **리소 판화** · 3도 인쇄 포스터 | 잉크 3색(형광 주황·파랑·노랑), 망점 명암, 판 어긋남 | 판이 크게 어긋나며 노란 망점 폭발 | 스크린샷 한 장으로 기억되는 개성 | 잉크 수가 공략 색과 충돌 (받기 예고 = 1P 색, 받기 불가 = 2P 색) |

### 각 스타일을 만드는 재료 (코드로 옮길 때)
모든 스타일이 **같은 셰이더 하나**를 다른 숫자로 쓴다. 게임에 옮길 때는 `STYLES` 항목 하나를 가져가면 된다.

- **툰 셰이더** (`FS_TOON`): 명암 경계 2개(`t1`, `t2`, `t2 > 1`이면 2단), 경계 부드러움, 그림자 색상 이동(`tint`), 림(폭·세기·자기 색), 하이라이트 띠, 그림자 무늬(0 없음 / 1 사선 해칭 / 2 망점)
- **외곽선** (`VS_HULL`): 뒤집은 껍데기를 **화면 픽셀 단위**로 밀어냄(720p 기준 px). 색 모드 3가지 — 고정색 / 물체 색을 어둡게 / 자기 색. 굵기 흔들림(먹선). 상자·원기둥 모서리가 갈라지지 않게 같은 자리 꼭짓점 법선을 평균 낸 `aOutN`을 씀
- **바닥** (`FS_FLOOR`): 민무늬 / 동심원 돌 타일 / 한지 + 붓 원 / 발광 격자 / 풀밭 + 흙길 / 망점. 게임의 안내 링(반지름 5, 9.5, 14)은 공통
- **후처리** (`FS_POST`): 종이 결, 입자감, 비네트, 판 어긋남, 블룸, 채도, 합 순간 효과 5종
- **아레나 소품**: 돌기둥 / 먹 깃발 / 등불 기둥 / 둥근 나무 / 단색 블록 + 먼 산 + 떠다니는 입자(먼지, 불티, 꽃잎, 먹 티끌)

## 검사에서 나온 것 (스크린샷 기준)

- **명도 검사에서 기준·구아슈·밤마당은 1P와 2P가 거의 같은 회색이다.** 주황과 하늘색이 명도가 비슷해서다. 색약 플레이어나 작은 화면에서 "누가 누구인지"가 흐려진다 → 공통 규칙 3번.
- **셀 애니는 흑백에서 주황 예고 원이 밝은 돌바닥에 묻힌다.** 채움을 진하게 올렸지만 명도 차이는 여전히 작다.
- **먹선과 네온이 명도 검사에서 가장 잘 버틴다.** 먹선은 종이 대 먹, 네온은 어둠 대 빛으로 명도 차가 크다.
- **실루엣**: 지금 캡슐 둘은 모양이 똑같아서 색을 빼면 1P/2P 구분이 안 된다. 제안 실루엣은 "넓적한 위"와 "뾰족한 위"로 구분된다.

## 어느 스타일을 고르든 지킬 것 (제안)

1. **받을 수 있는 공격 = 따뜻한 색 채움, 받을 수 없는 공격 = 사선 줄무늬.** 색만으로 구분하지 않는다. 비교판의 모든 스타일에 이미 적용했다(충격파의 사선). 리소처럼 잉크가 적은 스타일에서도 이것 덕분에 구분된다.
2. **금색은 합 전용.** 틈 부채꼴, 약점, 합 광선, 합 글자에만 쓴다. 네온의 등불도 일부러 금색을 피했다.
3. **두 캐릭터 색은 보색에 가깝게, 명도도 다르게.** 예: 1P 밝은 주황 / 2P 짙은 파랑(먹선의 인주·쪽빛 조합이 좋은 예).
4. **쿼터뷰는 머리 위가 보인다. 머리 위 모양을 다르게.** 제안 실루엣:
   - **A(1P)**: 짧고 단단한 몸 + 육각 망토 어깨 + 넓은 칼 → 위에서 보면 넓적함
   - **B(2P)**: 가늘고 긴 몸 + 뒤로 꺾인 뾰족 두건 + 휘날리는 끈 + 긴 창 → 위에서 보면 뾰족하고 길쭉함
   - 역할이 계속 교대되므로 "받는 캐릭터 / 치는 캐릭터"로 모양을 정하지 않았다. 캐릭터별 강점은 D 세션 몫.
5. **보스의 틈 자리를 몸에 미리 그려 둔다.** 제안 보스는 굽은 덩어리 + 작은 머리 + 비대칭 뿔 + **등껍질**. 받기가 성공하면 등껍질이 양옆으로 열리며 금빛 핵이 드러난다. 지금처럼 공중에 금색 구가 뜨는 것보다 "몸이 열렸다"가 읽힌다. 틈은 받은 사람 반대편에 열리고, 보스는 받은 사람을 보고 있으므로 대부분 등 쪽이 된다.
6. **합 연출은 스타일의 일부로 설계한다.** 같은 히트스톱이라도 집중선(애니), 흑백 반전(먹선), 과노출(네온), 판 어긋남(리소)으로 느낌이 크게 달라진다. A 세션("와" 연출)과 맞춰야 한다.

## E 세션(세계관)과의 연결

E 세션 문서(`docs/실험/E-구조와세계관.md`)가 세계관 **밤마당**(탈놀이의 밤, 횃불, 장단)을 제안하면서 비주얼을 이렇게 적었다.
- 팔레트: 밤 남색 바탕 + 횃불 주황 + 합은 금색, 오방색은 탈에만 포인트
- 외곽선: 목판화처럼 굵고 고르지 않은 선 (**C 세션 아트 탐색과 함께 볼 것**)

그래서 일곱째 스타일 **밤마당**을 따로 만들었다. 먹선의 선과 해칭을 밤으로 옮기고, 빛은 횃불에서만 오게 했다.
- 오방색 중 **황색은 뺐다.** 금(합 전용)과 겹친다.
- 남은 숙제: 횃불 주황, 1P 주황, 받기 예고 주황이 한 계열이다. 1P를 붉은 적색 쪽으로 옮기거나, 2P와 명도 차를 크게 벌려야 한다.

## 내 추천 (판단은 사용자)

1. 세계관이 밤마당으로 간다면 **밤마당**. 먹선의 장점(굵은 선, 반전 프레임)과 E의 톤(횃불, 밤, 금은 합에만)이 한 화면에 모인다. 단 위의 주황 겹침을 먼저 풀어야 한다.
2. 세계관과 상관없이 하나만 고르라면 **먹선**. 색을 두 사람과 금에만 쓰는 규칙이 "두 사람이 하나로 맞는 순간"을 화면 문법으로 만들고, 명도 검사에 가장 강하다.
3. 안전한 선택은 **셀 애니**. 레퍼런스 장르 문법이라 실패 위험은 낮지만, 이 게임만의 얼굴은 약하다.
4. **네온**은 신뢰(등 뒤의 빛)를 가장 잘 그리지만 보스 형태 읽기를 보완해야 한다.

## 한계

- 헤드리스 브라우저에서는 웹 글꼴이 막혀서, 스크린샷의 합 글자는 대체 글꼴이다. 게시본에서는 스타일별 글꼴(나눔붓, 주아, 도현, 검은고딕)이 나온다.
- 해칭·망점은 화면 공간 무늬라서 **움직일 때** 무늬가 미끄러지는 느낌은 스크린샷으로 확인할 수 없다. 재생해서 봐야 한다.
- 캐릭터·보스는 여전히 기본 도형이다. 실루엣 제안은 방향을 보여 주는 수준.
- 폰 GPU에서 여섯 칸을 동시에 그릴 때 프레임은 확인하지 못했다. 느리면 "하나씩"으로 보면 된다.
