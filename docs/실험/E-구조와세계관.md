| **별도 모드** | **한 마당** — 보스 하나만 골라 반복하는 보스 러시/연습. 지금 프로토타입이 곧 이 모드 |

## 1. 구조

### 1.1 세 후보 비교

반복 플레이에서 받기와 틈이 **죽는 길**은 세 가지다.

1. **외워져서 죽는다** — 보스 패턴을 다 외우면 합이 혼자 하는 안무가 되고, 파트너는 없어도 되는 존재가 된다
2. **강해져서 죽는다** — 숫자가 커져서 틈 없이 때려도 이기면 받을 이유가 사라진다
3. **묽어져서 죽는다** — 받기와 틈이 없는 시간(잡몹, 탐색, 파밍)이 길어지면 핵심 감정이 드물어진다

| 구조 | 외워짐 | 강해짐 | 묽어짐 | 판정 |
|---|---|---|---|---|
| **보스 러시** | 위험 큼. 같은 보스·같은 순서 → 안무화 | 안전 | 안전. 밀도 최고 | 핵심 밀도는 최고지만 반복에 약하다 → **별도 모드로 둔다** |
| **원정형 (밤의 통치자식)** | 안전. 매판 다른 빌드·순서 | 위험 큼. 스탯 성장이 받기를 대체 | 위험 큼. 필드 탐색·잡몹·파밍 시간이 길다. 고정 쿼터뷰 한 화면 2인이라 흩어져 탐색하기도 어색 | 뼈대는 좋다. **필드를 빼고 성장을 바꾸면 맞다** |
| **스테이지형** | 중간 | 중간 | 위험. 스테이지를 채울 잡몹이 필요 | 콘텐츠 소모가 크고 이 게임의 강점과 무관 |

### 1.2 제안: "하룻밤" — 필드 없는 원정형

**원정형의 뼈대(매판 다른 성장과 순서) + 보스 러시의 밀도(받기와 틈만 있는 시간).**

```
[해 질 녘]
   │
   ▼
 마당 1 ──▶ 골목 ──▶ 마당 2 ──▶ 골목 ──▶ 마당 3 ──▶ 골목 ──▶ 큰마당
 (작은 탈)  (고르기)  (작은 탈)  (고르기)  (작은 탈)  (준비)   (그날 밤의 큰탈)
                                                              │
                                                     [닭이 운다 = 클리어]
```

| 단위 | 길이 | 내용 |
|---|---|---|
| **마당** | 4~6분 | 보스급 적 1체(작은 탈). 크고 읽히는 예비 동작, 받기와 틈 규칙 그대로 |
| **골목** | 30초~1분 | 다음 마당 2곳 중 하나 고르기(보상 종류가 보인다) + 가락 고르기 / 쉼 / 장단 맞추기 |
| **큰마당** | 8~10분 | 그날 밤의 큰탈. 페이즈 3개, 마지막 페이즈에 **맞받기**(둘 다 받아야 열리는 틈) |
| **한 판** | 25~35분 | 친구와 한 번 앉아서 한두 판. 로컬 협동의 호흡에 맞춘 길이 |

**규칙 세 가지**

1. **잡몹 없음.** 화면에 나오는 모든 적은 받기와 틈을 따른다. 작은 적이 필요하면 "탈의 손발"처럼 보스에 딸린 부속으로만 쓴다.
2. **필드 없음.** 이동은 골목에서 고르기로 끝난다. 쿼터뷰 고정 카메라 한 화면에 두 사람이 늘 함께 있다 — 늘 서로의 등이 보이는 구조.
3. **한 판 안에서만 강해진다.** 판이 끝나면 가락은 사라진다. 판 밖에서 쌓이는 건 힘이 아니라 **선택지와 이야기**(1.5).

### 1.3 성장: 가락 — "자리에 붙는 성장"

**핵심 원칙: 성장은 사람이 아니라 자리에 붙는다.**

가락은 "받은 사람에게", "친 사람에게", "합이 터지면 둘에게" 붙는다. 보스 시선이 합을 친 사람에게 넘어가서 역할이 저절로 바뀌므로, **같은 가락을 두 사람이 번갈아 쓴다.** 한 사람만 세지는 일이 구조적으로 없다.

| 자리 | 가락 예시 | 만드는 감정 |
|---|---|---|
| **받는 자리** | **징 울림** — 정확한 받기 시 틈이 0.3초 길어진다 | "네가 잘 받아서 내가 크게 쳤다" |
| | **버팀목** — 버티기로 받아도 틈이 정확한 받기의 70% 크기로 열린다 | 받기가 서툰 사람도 받는 자리를 맡을 수 있다 |
| | **되받기** — 반동 중 보스 시선을 한 번 더 붙잡는다 | 등을 맡기는 신뢰 (치는 사람이 맘 놓고 들어간다) |
| **치는 자리** | **선손** — 받기 직전 공격도 완벽한 합으로 인정하는 창이 넓어진다 | **믿고 먼저 휘두르기**에 대한 보상 = 신뢰 |
| | **뒷박** — 합 직후 짧은 추가 타격 창 | 끝내 주는 기쁨 |
| **맞물림** (합이 터질 때만) | **자리 바꿈** — 완벽한 합 시 두 사람의 위치가 빛으로 바뀐다 | 역할 교대가 눈에 보인다 |
| | **이어치기** — 합이 끊기지 않고 이어질수록 다음 합 배율이 오른다. 둘 다 받으면 끊긴다 | 합의 쾌감 + 내 거/네 거 판단에 무게 |
| | **메아리** — 다음 한 번의 틈이 양쪽으로 열린다 | 드문 보상. "이번만은 둘 다 쳐!" |

**금지하는 가락** (반복에서 받기와 틈을 죽이는 것들)
- 공격력·체력 같은 평평한 스탯 상승
- 자동으로 피해를 주는 것(소환수, 지속 피해 장판)
- 혼자서 틈을 열고 혼자서 치게 해 주는 것
- 틈 밖 공격을 크게 키우는 것

**골목의 화폐: 신명**
- 합을 칠 때 신명이 쌓인다. 완벽한 합 > 합 > 정확한 받기. 틈 밖 공격은 0.
- 골목에서 신명으로 가락을 고른다. → **합의 질이 곧 경제**다. 깎아서만 이긴 판은 가난하다.

### 1.4 반복에서 살아남는 장치

| 위험 | 장치 | 설명 |
|---|---|---|
| 외워짐 | **장단 변주** | 보스의 공격은 장단(구절) 단위로 짜여 있다. 예비 동작은 항상 같고(읽힘 유지), 구절 순서·박자·마지막 공격이 매판 바뀐다. "다음이 뭔지"는 몰라도 "보면 안다" |
| 외워짐 | **누가 노려지는가** | 사이 공격·돌진은 두 사람의 위치로 대상이 정해진다. 위치가 매번 다르니 "내 거/네 거" 판단이 매번 새로 생긴다 |
| 외워짐 | **탈의 기분** | 같은 탈도 밤마다 기분이 있다 — 성난 탈(빠름), 취한 탈(엇박), 짝탈(두 탈이 한 마당에 나와 시선이 갈림) |
| 강해짐 | **자리 가락 + 금지 목록** | 1.3 |
| 강해짐 | **금(균열)** | 탈은 **합으로만 금이 간다.** 틈 밖 공격은 체력은 깎아도 금을 못 낸다. 금이 다 차야 탈이 벗겨지고 끝난다. → 깎아서 이기는 길이 세계 규칙으로 막힌다 *(전투 세션과 겹치는 부분 — 9절 참고)* |
| 묽어짐 | **잡몹·필드 없음** | 1.2 |
| 질림 | **깊은 밤** | 클리어 후 여는 난이도 단계. 스탯이 아니라 **판정과 패턴**을 조인다 — 정확한 받기 판정이 좁아짐, 사이 공격이 잦아짐, 맞받기가 큰마당 전에도 나옴, 짝탈 등장 |
| 질림 | **짝이 바뀐다** | 같은 보스도 다른 짝(사람이든 캐릭터든)과 하면 다른 판이 된다. 복식에서 같은 코트가 질리지 않는 이유와 같다 — **콘텐츠는 상대와 파트너다** |

### 1.5 판 밖에서 쌓이는 것 (메타)

힘은 쌓지 않는다. 쌓이는 것은:

- **탈 장롱** — 벗긴 탈을 모은다. 탈마다 "탈 너머 얼굴" 짧은 이야기 한 토막
- **가락 늘리기** — 새 가락이 골목에 나타나기 시작한다(선택지가 넓어질 뿐 강해지지 않음)
- **새 잡이** — 캐릭터 해금 (캐릭터 수는 미정. 3.3 참고)
- **합 한 장면** — 그 판의 가장 좋았던 완벽한 합을 한 장면으로 남긴다(결과 화면). 둘이 나눠 가지는 기념사진

### 1.6 모드

| 모드 | 내용 |
|---|---|
| **하룻밤** (메인) | 1.2의 런. 솔로(태그)와 듀오 공통 |
| **한 마당** | 해금한 탈 하나를 골라 바로 싸운다. 가락 없음. 기록(걸린 시간, 완벽한 합 수). **지금 프로토타입이 이 모드다** |
| **짝 합류** | 혼자 하룻밤을 하다가 골목에서 2P가 들어올 수 있다. 로컬 협동에서 "잠깐 나도 해 볼래"를 받아 주는 장치 |

### 1.7 쓰러짐과 다시 들어오기 (실수 메워 주기)

- 쓰러진 사람은 **마당 가장자리**로 물러나 구경꾼 자리에 선다.
- 남은 사람이 **정확한 받기**에 성공하면, 쓰러졌던 사람이 **열린 틈으로 뛰어들며 복귀**한다. 이 진입 공격은 합으로 친다.
- → 복귀 자체가 합이 된다. 혼자 남은 사람이 "받아 줄게, 들어와"를 몸으로 말한다.
- 솔로에서는 이 자리가 태그 대기석과 같다(3.2).

*(전투 규칙에 걸치는 제안이라 프로토타입 반영은 하지 않았다.)*

## 2. 세계관 — 밤마당

### 2.1 한 문단

> 마지막 탈놀이가 끝나지 않았다.
> 놀이가 끝나면 탈을 태워 액을 보내야 하는데, 그해에는 아무도 탈을 태우지 못했다.
> 탈들은 스스로 춤을 이어 갔고, 그날부터 밤이 끝나지 않는다.
> 탈은 혼자 내는 소리로는 깨지지 않는다. **앞에서 받아 주는 소리와 뒤에서 치는 소리가 한 박에 겹칠 때만 금이 간다.**
> 그래서 잡이들은 언제나 둘이 한 짝으로 마당에 선다.

탈놀이 뒤에 탈을 태우던 풍습에서 착안했다. 실제 풍습을 그대로 옮기는 게 아니라 분위기의 출발점으로만 쓴다.

### 2.2 메커니즘이 세계 규칙이 된다

| 게임 규칙 | 세계 안에서의 이유 |
|---|---|
| 받기와 틈 | 탈은 **앞뒤에서 동시에 눌러야** 금이 간다. 한쪽 힘만으로는 탈이 그 힘 쪽으로 쏠릴 뿐이다 → 받은 반대편이 열린다 |
| 받은 사람은 못 친다 | 탈의 힘을 정면으로 받으면 몸이 울린다(반동). 같은 사람이 앞뒤를 동시에 누를 수는 없다 |
| 둘 다 받으면 틈이 날아간다 | 앞에서만 둘이 누르면 탈은 뒤로 물러날 뿐 금이 가지 않는다 |
| 완벽한 합 | 두 소리가 **한 박에** 겹친 것. 금이 가장 크게 간다 |
| 합 친 사람에게 시선이 넘어감 | 탈은 자기에게 금을 낸 소리를 쫓는다 |
| 솔로 태그 | 탈춤처럼 잡이는 **마당 가장자리에서 들어오고 나간다.** 태그 진입 = 마당에 뛰어드는 것 |
| 보라 공격(받기 불가) | 탈의 **그늘** — 소리가 닿지 않는 것. 받을 수 없으니 피한다 |
| 주황 공격(받기 가능) | 횃불빛에 드러난 **몸짓** — 소리로 받아칠 수 있다 |

### 2.3 주인공: 잡이

풍물에서 악기를 맡은 사람을 **잡이**라고 부른다(쇠잡이, 징잡이, 장구잡이, 북잡이).
"잡이"는 **붙잡는 사람**이라는 뜻으로도 읽힌다 — 받는 자리와 겹친다.

사물놀이의 네 악기는 전통적으로 날씨에 빗댄다. 이것을 캐릭터의 씨앗으로 쓸 수 있다 *(캐릭터 설계는 D 세션 담당. 여기서는 세계가 주는 재료만 적는다)*.

| 잡이 | 악기 = 무기 | 날씨 | 자연스러운 강점 (안 C의 씨앗) |
|---|---|---|---|
| **징잡이** | 징 (큰 쇠판) | 바람 | 받기. 징으로 막으면 길게 울린다 → 큰 틈 |
| **쇠잡이** | 꽹과리와 채 | 번개 | 치기. 빠르고 짧다 → 완벽한 합 노리기 |
| **북잡이** | 북과 북채 | 구름 | 무거운 한 방. 늦지만 큰 합 |
| **장구잡이** | 장구, 궁채와 열채 | 비 | 두 손 따로. 받기와 치기 사이를 오가는 만능 |

**합의 소리 = 두 악기가 한 박에 맞는 소리.** 기획서의 "두 음이 겹치는 화음 같은 타격음"이 세계 안에서 그대로 성립한다. 짝마다 합 소리가 다르다(징+쇠, 북+장구…). 같은 보스도 짝을 바꾸면 소리부터 다르다.

### 2.4 적: 탈

- **작은 탈** — 마당의 보스. 탈놀이의 배역에서 성격을 빌린다(배역 이름 그대로가 아니어도 된다).
- **큰탈** — 그날 밤의 마지막. 큰마당에 나온다.
- 탈의 몸은 옷과 천으로 되어 있다. **긴 소매(한삼)**가 공격의 궤적을 그린다 → 밤의 통치자식 "크고 읽히는 예비 동작"을 소매 자락으로 보여 준다.
- 탈에는 **금**이 간다. 합마다 금이 늘어나고, 다 차면 탈이 벗겨진다(1.4).
- 벗겨진 탈 밑에는 **얼굴**이 있다 — 그 탈을 쓰고 마지막 놀이를 하던 누군가의 사연. 한 판에 한 토막씩 풀린다.

보스 아이디어 (B 세션 참고용 씨앗)

| 탈 | 성격 | 받기와 틈에서의 시험 |
|---|---|---|
| **떠버리 탈** | 수다스럽고 빠른 첫 상대 | 기본기. 받기 가능 공격 위주 |
| **취한 탈** | 박자를 밀고 당긴다 | 엇박 예비 동작 → 정확한 받기 타이밍 시험 |
| **삼키는 탈** | 큰 입, 잡기 | 받기 불가(그늘) 공격이 많다 → "받을까 피할까" |
| **늙은 중 탈** | 느리고 무겁다 | 연속 공격, 마지막 받기에서 큰 틈 |
| **사자** | **두 사람이 들어간 사자탈** | **거울 보스.** 보스도 앞발이 받고 뒷발이 친다. 플레이어가 보스의 합을 끊어야 한다 |
| **빈 탈** (큰탈) | 얼굴 없는 탈. 밤 그 자체 | 마지막 페이즈 **맞받기** — 평소 규칙을 뒤집어 둘이 함께 받아야 열린다 |

### 2.5 구경꾼과 추임새

- 마당 가장자리에 마을 사람들이 둘러서 있다(실루엣, 횃불).
- 합이 터지면 **추임새**가 터진다 — "좋다!", "얼쑤!", 완벽한 합이면 마당 전체가 들썩인다.
- **"와" 소리를 게임 안의 사람들이 먼저 내 준다.** 연출(A 세션)과 바로 이어지는 재료.
- 숫자 UI 대신 구경꾼의 반응으로 합의 질을 알게 한다(기획서의 "UI는 최소화. 숫자보다 느낌으로").

## 3. 톤

### 3.1 한 단어: 신명

무섭지 않다. **들뜬 밤이다.** 슬픔은 있지만 탈 밑에 숨어 있다가 탈이 벗겨질 때만 잠깐 보인다.

| 축 | 이쪽 | 저쪽이 아님 |
|---|---|---|
| 분위기 | 축제 같은 밤, 횃불, 북소리 | 공포, 폐허, 절망 |
| 유머 | 탈춤의 익살, 보스에게도 성격 | 진지한 비장미 일색 |
| 슬픔 | 탈 밑의 사연, 짧고 조용하게 | 긴 컷신, 설명 |
| 두 사람 | 말 없이 맞는 사이 | 대사로 우정을 설명 |

### 3.2 솔로의 이야기

솔로는 "혼자 두 사람 몫을 치는 잡이"가 아니라 **"마당 가장자리에서 기다리는 짝을 불러들이는 사람"**이다. 태그 대기석 = 마당 가장자리 = 쓰러진 사람이 서는 자리(1.7). 세 상황이 한 장소로 묶인다.

### 3.3 캐릭터 수에 대한 의견 (미정 항목)

**로스터에서 둘 고르기를 추천한다** (4명으로 시작).
- 이유: 반복의 재료가 "짝"이므로, 짝 조합이 늘어나는 것이 곧 콘텐츠다. 4명 → 6가지 짝.
- 짝마다 합 소리와 짝 이름이 다르다(예: 징+쇠 = "바람번개").
- 다만 시작은 2명으로 충분하다. 구조는 2명 고정에서도 그대로 성립한다.

### 3.4 시각과 소리

| 항목 | 방향 |
|---|---|
| 팔레트 | 밤 남색 바탕 + 횃불 주황 + **합은 금색**. 오방색은 탈에만 포인트로 *(지금 프로토타입의 밤·금·보라와 그대로 이어진다)* |
| 외곽선 | 목판화처럼 굵고 고르지 않은 선 (C 세션 아트 탐색과 함께 볼 것) |
| 아레나 | 둥근 흙마당, 가장자리 횃불과 구경꾼, 위로 보이는 새끼줄과 천 |
| 실루엣 | 탈은 머리가 크고 소매가 길다 → 쿼터뷰에서 방향과 공격 궤적이 잘 읽힌다 |
| 음악 | 보스의 장단이 페이즈마다 빨라진다(느린 장단 → 빠른 장단). 공격 구절이 장단에 실려 있어 **귀로도 읽힌다** |
| 주의 | 박자에 맞춰야 이기는 리듬 게임이 되면 안 된다. 장단은 읽기를 돕는 재료일 뿐 판정은 기존 그대로 |

## 4. 다른 방향 (밤마당이 안 맞을 때)

구조(1장)는 세계관과 상관없이 성립한다. 세계관만 갈아 끼울 수 있다.

| 대안 | 한 줄 | 받기와 틈의 이유 |
|---|---|---|
| **메질꾼** | 꺼지지 않는 쇠를 벼리는 밤. 집게잡이와 메질꾼 둘이 한 조 | 한 명이 붙잡아 버티고 다른 한 명이 내려친다 |
| **등불지기** | 빛을 먹는 것들이 오는 밤, 등불 하나를 둘이 지킨다 | 등을 든 사람이 막아 서고, 그 빛이 드리운 그림자 쪽에서 짝이 친다 |

## 6. 판단이 필요한 것

1. **구조**: "하룻밤"(필드 없는 원정형) + "한 마당"(보스 러시 모드) 조합으로 가도 되는가
2. **세계관**: 밤마당(탈과 풍물) 방향이 마음에 드는가, 아니면 4장 대안이나 전혀 다른 방향인가
3. **금**: "탈은 합으로만 깨진다"를 승리 조건으로 둘 것인가 (반복에서 받기와 틈을 지키는 가장 강한 장치지만, 전투 규칙을 건드린다)
4. **캐릭터 수**: 로스터에서 둘 고르기(4명 시작)를 추천 — 동의하는가
5. **"맛있는 액션게임이면서 동시에 ___"**: 이 세계관에서 떠오르는 후보는 "신명 나는 놀이판", "둘이 하는 한 판 굿". 사용자의 원래 문장이 따로 있다면 그게 우선이다
